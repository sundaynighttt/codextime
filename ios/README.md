# CodexTime for iPhone

작은 카드와 소형 위젯에 **Codex / Grok / Claude** 로고·잔여율을 가로 3열로 표시합니다. Codex는 직접 조회하고 지원되는 공식 웹 사용량 화면은 수동 확인합니다. 계정·로그인 방식별 제약이 있어 Grok·Claude의 모든 계정 E2E를 보장하지 않습니다.

최신 TestFlight 빌드 **1.0(16)**는 Claude 사용량을 한 번 읽어 현재 세션·전체 모델 주간 잔여율을 따로 저장하고 앱·위젯에 표시합니다. **80개 XCTest·최종 Release·archive 서명**을 통과했고 **2026-10-19 23:40:44 KST 업로드·23:43:46 KST Apple 테스트 가능 알림**으로 기존 테스터의 설치·업데이트 가능을 확인했습니다. [동작·검증·배포 기록](../docs/releases/2026-10-19-claude-usage-reader.md). 빌드15의 Google/새창 제한·화면 복구는 유지하며 [이전 기록](../docs/releases/2026-10-19-claude-login-recovery.md)에 보존합니다.

이전 TestFlight 빌드 **1.0(14)**는 웹 로그인 영역을 확대했습니다. 큰 안내와 숫자 설정은 필요할 때 시트로 열고 하단은 작은 한 줄로 표시하며, 키보드가 열리면 하단을 숨깁니다. iPhone 17e의 빈 로그인 폼·Release 화면·42개 테스트·서명 검증을 통과했습니다. **2026-10-19 21:39:25 KST 업로드, 21:42~21:43 KST Apple 처리 완료·90일 유효·Internal 내부 1명 배정, 21:44 KST 한국어 테스트 안내 저장**을 확인했습니다. [UI 수리 기록](../docs/releases/2026-10-19-ios-web-height.md).

Apple 처리 확인 최신은 **1.0(16)**이며 iOS17 이상 iPhone의 [기존 테스터용 TestFlight](https://testflight.apple.com/v1/app/6805935440)에서 업데이트할 수 있습니다. 정확한 빌드16 그룹 UI·인원과 사용자 기기 설치 완료는 미확인입니다. 사용자는 Claude 로그인 성공과 사용량 패널 도달을 보고했습니다. 새 읽기의 iPhone 실계정 숫자·캐시·위젯 대조는 별도 확인이 필요합니다. 빌드14의 Grok 로그인 성공 및 이전 UI·배포 이력은 보존합니다.

**1.0(16)**의 Claude **사용량 읽기**는 공식 화면에서 현재 세션·전체 모델 주간의 짧은 허용 라벨과 meter 숫자를 기기 내에서 구분합니다. 두 한도를 모두 검증해야 갱신하며 부분 결과·실패는 이전 값과 시각을 유지합니다. 주간을 대표로, 세션을 앱·위젯에 별도로 표시하고 모델별 한도는 제외합니다. 실제 Desktop DOM 구조·합성 시험·Release 화면 검증은 iPhone 실계정 E2E와 구분합니다.

## 서비스별 연결

- **Codex:** 기존 OpenAI 공식 기기 로그인으로 본인 ChatGPT 계정에 연결하고 직접 사용량을 조회합니다. 리셋·누적 토큰을 유지합니다.
- **Grok:** **Grok 연결·확인**에서 지원되는 공식 로그인 후 주간 퍼센트를 수동 확인합니다. 사용자 실기기 로그인 성공 보고는 있으나 모든 계정이나 사용량·위젯 E2E 성공을 보장하지 않습니다.
- **Claude:** Google OAuth는 앱 내부 WKWebView에서 지원하지 않으며 공식 이메일 대안을 안내합니다. 사용자의 로그인·사용량 패널 도달 보고는 확인됐지만 빌드16의 현재 세션/주간 숫자 추출·캐시·위젯의 실계정 대조는 미검증입니다.

이미 저장 값이 있으면 **다시 확인**으로 웹을 엽니다. **빌드16의 Claude**는 세션·주간 한도가 보이는 공식 사용량 패널에서 **사용량 읽기**를 한 번 누릅니다. 별도 의미·한도 선택이나 숫자 위치 탭을 요구하지 않습니다. 정해진 라벨·구조·숫자가 맞지 않으면 읽기를 중단합니다. **Grok**은 기존 **사용량 열기 → 읽기 설정**에서 숫자가 보임·사용함/남음·주간을 선택한 뒤 **숫자 읽기**를 누르고 15초 안에 해당 퍼센트를 직접 탭합니다. 사용함 수치는 잔여율로 바꾸며 공급자·한도·모델별 숫자를 복제하거나 합치지 않습니다. 도움말은 **더 보기 → 도움말**에서 엽니다.

웹 로그인은 각 `nonPersistent WKWebView`에서 처리하고 앱 실행 중 메모리에만 유지합니다. 화면을 닫아도 같은 실행 중에는 유지될 수 있으나 앱 종료·연결 해제 뒤에는 재로그인이 필요합니다. 지원되는 로그인·추가 인증은 공식 웹에서 사용자가 직접 처리합니다. Google/새창 흐름에는 별도 제한 안내가 적용되며 모든 SSO가 지원되는 것은 아닙니다. 앱은 Safari·Mac·다른 앱의 쿠키나 토큰을 가져오지 않습니다. Mac·iCloud·Cursor·별도 서버·API 키가 필요하지 않습니다.

## Claude 이메일 대안과 복귀

기존 Claude 계정과 **같은 이메일**로 공식 [이메일 로그인 안내](https://support.claude.com/en/articles/13189465-log-in-to-your-claude-account)를 따릅니다. 다른 기기에서 메일 링크를 열어 코드가 나오면 로그인 요청을 시작한 원래 공식 웹 화면에 직접 입력합니다. 이전 링크 확인 오류 보고 뒤 사용자가 Claude 로그인·사용량 패널 도달을 보고했습니다. 열린 환경·이전 오류의 만료·이미 사용 여부와 정확한 원인은 확정하지 않습니다. 새 빌드16 파서·캐시·위젯의 실제 숫자 대조는 사용자 TestFlight 검증 대기입니다. Google 연결 해제·권한 변경을 요구하지 않습니다.

빌드15는 뒤로·새로고침·고정 사용량 복귀 및 오류 복구를 제공합니다. Google OAuth 완료를 지원하는 변경은 아니며 검증한 것은 제한 안내와 Claude 화면 복귀입니다. 외부 Safari/ASWebAuthenticationSession 로그인이 현재 WKWebView로 자동 이전되지 않으며 쿠키·토큰을 복사하지 않습니다. [Google 공식 제약](https://developers.google.com/identity/protocols/oauth2/native-app#disallowed_useragent)을 우회하지 않습니다.

## 표시·저장·삭제

- 카드와 위젯은 기본 3열입니다. 웹 값에는 **수동 확인·선택 한도·확인 시각**을 표시하고 1시간 뒤에는 **지난 확인**으로 구분합니다.
- 위젯은 마지막 수동 숫자만 읽습니다. Codex 새로고침이나 30분 위젯 갱신 요청이 웹 사용량을 다시 조회하지 않습니다. 실제 WidgetKit 갱신 시점은 iOS가 결정합니다.
- 서비스 구분·퍼센트·사용함/남음 의미·한도·확인 시각만 기기 App Group 캐시에 보관합니다. 빌드16 후보는 Claude 세션·주간 두 숫자가 모두 검증된 경우에만 한도별로 갱신합니다. 한쪽 실패·부분 결과는 두 이전 숫자·확인 시각을 유지합니다. 앱 종료 후에도 숫자는 남습니다. 원시 웹 텍스트·쿠키·인증 토큰·계정 ID/이메일은 저장하지 않습니다.
- **웹 사용량 관리 → 연결 해제·기록 삭제**는 해당 서비스의 메모리 웹 세션과 숫자 기록을 지웁니다. 계정을 바꿀 때 먼저 이전 기록을 지우세요. 공급자 계정·구독 삭제와는 다릅니다.
- 예시 모드는 로그인·네트워크 없이 별도 Codex 샘플을 보여줍니다. 실제 웹 숫자를 예시 카드·위젯에 섞지 않습니다.
- 광고·분석 SDK·개발자 중계 서버·iCloud 동기화는 없습니다.

## 배포와 이전 후보

실제 Apple 처리 확인 최신은 **1.0(16)**이며 Apple 테스트 가능 알림으로 기존 테스터가 설치·업데이트할 수 있음을 확인했습니다. 정확한 그룹 UI·인원과 사용자 iPhone 설치·숫자·위젯 대조는 별도 확인 항목입니다. 사용자 로그인·사용량 패널 도달 보고를 새 읽기의 실계정 E2E 완료로 확대하지 않습니다. 빌드13~15의 이력은 유지하며 정식 App Store 공개나 새 공개 초대 링크 생성은 수행하지 않았습니다.

이전 **1.0(11)**은 2026-10-19 13:37:25 KST 업로드 후 13:38:53 KST Apple ready-to-test를 확인했고, 이후 ASC에서 CodexTime Internal 그룹 1명·빌드 11 설치 표시 1을 확인했습니다. 설치 집계는 기능 smoke 성공의 증거가 아닙니다. 빌드 11은 Codex 직접 조회와 3열 UI만 지원하며 Grok·Claude는 미지원입니다.

iCloud 후보 **1.0(12) / Mac 0.3.1(2026101907)**은 로컬 검증 후 서명·프로필 문제로 중단·미배포했습니다. 현재 웹 후보에 포함하지 않습니다. [보존 이력](../docs/releases/2026-10-19-private-icloud-sync.md) · [원장](../docs/releases/release-ledger.json) · [제출 현황](../docs/app-store/submission.md).

## 직접 빌드

1. Xcode 16 이상과 [XcodeGen](https://github.com/yonaskolb/XcodeGen)을 설치합니다.
2. `ios` 폴더에서 `xcodegen generate`를 실행하고 `CodexTime.xcodeproj`를 엽니다.
3. 앱과 위젯의 Signing Team, 번들 ID, App Group `group.com.sundaynighttt.codextime`, Keychain Sharing을 자신의 팀에 맞게 함께 설정합니다. 별도 CloudKit 컨테이너는 필요하지 않습니다.

저장소 루트에서 시뮬레이터 빌드·단위 테스트를 실행할 수 있습니다.

```bash
./ios/scripts/test-ios.sh
```

## 개인정보와 서비스 경계

Codex 토큰은 동기화되지 않는 기기 전용 Keychain에 저장하고 서명된 앱과 위젯만 공유합니다. 인증 ID 토큰에 계정 정보가 포함될 수 있으며 실제 Codex 인증·사용량 요청은 OpenAI에 직접 전달됩니다. 웹 로그인·페이지 열기는 해당 공급자와 로그인 제공자로 직접 전달됩니다. 앱은 웹 세션을 내보내지 않고 명시적 수동 확인의 숫자·한도·시각만 로컬에 저장합니다.

비공식 앱이며 공개 소스·로그인 성공이 공급자의 타사 이용 허가나 App Store 승인을 증명하지 않습니다. [개인정보 처리방침](../docs/privacy-policy.md)을 확인하고 토큰·계정 응답·실제 수치를 공개 이슈에 첨부하지 마세요.
