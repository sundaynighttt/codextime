# CodexTime for iPhone

작은 카드와 소형 위젯에 **Codex / Grok / Claude** 로고·잔여율을 가로 3열로 표시합니다. Codex는 직접 조회하고 지원되는 공식 웹 사용량 화면은 수동 확인합니다. 계정·로그인 방식별 제약이 있어 Grok·Claude의 모든 계정 E2E를 보장하지 않습니다.

최신 개발 후보 **1.0(15)**는 Claude Google/새창 제한 안내와 부모 페이지 보존, 뒤로·새로고침·공식 사용량 복귀·오류 복구를 보강했습니다. **51개 XCTest·Release의 제한 안내/화면 복귀·빈 이메일/키보드·archive 서명을 검증했고 2026-10-19 22:38:48 KST 업로드에 성공했으며 Apple 처리·그룹 배정은 확인 대기**이며 Apple 처리 확인 최신은14를 유지합니다. [조사·후보 기록](../docs/releases/2026-10-19-claude-login-recovery.md).

최신 TestFlight 빌드 **1.0(14)**는 웹 로그인 영역을 확대했습니다. 큰 안내와 숫자 설정은 필요할 때 시트로 열고 하단은 작은 한 줄로 표시하며, 키보드가 열리면 하단을 숨깁니다. iPhone 17e의 빈 로그인 폼·Release 화면·42개 테스트·서명 검증을 통과했습니다. **2026-10-19 21:39:25 KST 업로드, 21:42~21:43 KST Apple 처리 완료·90일 유효·Internal 내부 1명 배정, 21:44 KST 한국어 테스트 안내 저장**을 확인했습니다. [UI 수리 기록](../docs/releases/2026-10-19-ios-web-height.md).

Apple 처리 확인 최신은 **1.0(14)**이며 기존 CodexTime Internal 그룹 1명이 TestFlight에서 설치·업데이트할 수 있습니다. 사용자는 실기기 Grok 로그인 성공과 Claude Google 로그인 뒤 흰 화면·복귀 불가를 보고했습니다. 실제 사용량 읽기·위젯 E2E까지 완료했다고 추정하지 않습니다. [빌드14 기록](../docs/releases/2026-10-19-ios-web-height.md)에 최신 UI·배포를, [빌드13 기록](../docs/releases/2026-10-19-ios-web-usage.md)에 기존 기능·검증을 구분합니다.

## 서비스별 연결

- **Codex:** 기존 OpenAI 공식 기기 로그인으로 본인 ChatGPT 계정에 연결하고 직접 사용량을 조회합니다. 리셋·누적 토큰을 유지합니다.
- **Grok:** **Grok 연결·확인**에서 지원되는 공식 로그인 후 주간 퍼센트를 수동 확인합니다. 사용자 실기기 로그인 성공 보고는 있으나 모든 계정이나 사용량·위젯 E2E 성공을 보장하지 않습니다.
- **Claude:** Google OAuth는 앱 내부 WKWebView에서 지원되는 흐름으로 안내하지 않습니다. 빌드15 후보는 해당 진입을 중단·설명하고 공식 이메일 대안을 안내합니다. 실제 이메일 로그인·현재 세션/주간 퍼센트 확인의 완료는 미검증입니다.

이미 저장 값이 있으면 **다시 확인**으로 웹을 엽니다. 빌드14 UI에서는 로그인 후 **사용량 열기 → 읽기 설정**에서 **사용량 숫자가 화면에 보입니다**, **사용함/남음**, 읽을 한도를 정합니다. 설정을 완료한 뒤 **숫자 읽기**를 누르고 15초 안에 해당 퍼센트를 직접 탭합니다. 도움말은 상단 **더 보기 → 도움말**에 있습니다. 지원하는 주소·화면 구조·숫자를 확인하지 못하면 중단합니다. 사용함 수치는 잔여율로 바꾸며 공급자·한도 사이 수치를 복제하거나 합치지 않습니다.

웹 로그인은 각 `nonPersistent WKWebView`에서 처리하고 앱 실행 중 메모리에만 유지합니다. 화면을 닫아도 같은 실행 중에는 유지될 수 있으나 앱 종료·연결 해제 뒤에는 재로그인이 필요합니다. 지원되는 로그인·추가 인증은 공식 웹에서 사용자가 직접 처리합니다. Google/새창 흐름에는 별도 제한 안내가 적용되며 모든 SSO가 지원되는 것은 아닙니다. 앱은 Safari·Mac·다른 앱의 쿠키나 토큰을 가져오지 않습니다. Mac·iCloud·Cursor·별도 서버·API 키가 필요하지 않습니다.

## Claude 이메일 대안과 복귀 후보

기존 Claude 계정과 **같은 이메일**로 공식 [이메일 로그인 안내](https://support.claude.com/en/articles/13189465-log-in-to-your-claude-account)를 따릅니다. 다른 기기에서 메일 링크를 열어 코드가 나오면 로그인 요청을 시작한 원래 공식 웹 화면에 직접 입력합니다. 실제 앱 내 완료는 아직 검증하지 않았고 Google 연결 해제·권한 변경을 요구하지 않습니다.

빌드15는 뒤로·새로고침·고정 사용량 복귀 및 오류 복구를 제공합니다. Google OAuth 완료를 지원하는 변경은 아니며 검증한 것은 제한 안내와 Claude 화면 복귀입니다. 외부 Safari/ASWebAuthenticationSession 로그인이 현재 WKWebView로 자동 이전되지 않으며 쿠키·토큰을 복사하지 않습니다. [Google 공식 제약](https://developers.google.com/identity/protocols/oauth2/native-app#disallowed_useragent)을 우회하지 않습니다.

## 표시·저장·삭제

- 카드와 위젯은 기본 3열입니다. 웹 값에는 **수동 확인·선택 한도·확인 시각**을 표시하고 1시간 뒤에는 **지난 확인**으로 구분합니다.
- 위젯은 마지막 수동 숫자만 읽습니다. Codex 새로고침이나 30분 위젯 갱신 요청이 웹 사용량을 다시 조회하지 않습니다. 실제 WidgetKit 갱신 시점은 iOS가 결정합니다.
- 서비스 구분·퍼센트·사용함/남음 의미·선택 한도·확인 시각만 기기 App Group 캐시에 보관합니다. 앱 종료 후에도 숫자는 남습니다. 원시 웹 텍스트·쿠키·인증 토큰·계정 ID/이메일은 저장하지 않습니다.
- **웹 사용량 관리 → 연결 해제·기록 삭제**는 해당 서비스의 메모리 웹 세션과 숫자 기록을 지웁니다. 계정을 바꿀 때 먼저 이전 기록을 지우세요. 공급자 계정·구독 삭제와는 다릅니다.
- 예시 모드는 로그인·네트워크 없이 별도 Codex 샘플을 보여줍니다. 실제 웹 숫자를 예시 카드·위젯에 섞지 않습니다.
- 광고·분석 SDK·개발자 중계 서버·iCloud 동기화는 없습니다.

## 배포와 이전 후보

실제 Apple 처리 확인 최신은 **1.0(14)**입니다. 기존 CodexTime Internal 그룹 1명에게 배정됐으며 사용자 실기기 Grok 로그인 성공·Claude Google 로그인 후 문제 보고를 기록하며 전체 계정 기능·위젯 검증 완료로 확대하지 않습니다. 빌드13의 기존 기능과 배포 이력은 유지합니다. 정식 App Store 공개나 새 공개 초대 링크 생성은 수행하지 않았습니다.

이전 **1.0(11)**은 2026-10-19 13:37:25 KST 업로드 후 13:38:53 KST Apple ready-to-test를 확인했고, 이후 ASC에서 CodexTime Internal 그룹 1명·빌드 11 설치 표시 1을 확인했습니다. 설치 집계는 기능 smoke 성공의 증거가 아닙니다. 빌드 11은 Codex 직접 조회와 3열 UI만 지원하며 Grok·Claude는 미지원입니다.

iCloud 후보 **1.0(12) / Mac 0.3.1(2026101907)**은 로컬 검증 후 서명·프로필 문제로 중단·미배포했습니다. 현재 웹 후보에 포함하지 않습니다. [보존 이력](../docs/releases/2026-10-19-private-icloud-sync.md) · [원장](../docs/releases/release-ledger.json) · [제출 현황](../docs/app-store/submission.md).

## 직접 빌드

1. Xcode 16 이상과 [XcodeGen](https://github.com/yonaskolb/XcodeGen)을 설치합니다.
2. `ios` 폴더에서 `xcodegen generate`를 실행하고 `CodexTime.xcodeproj`를 엽니다.
3. 앱과 위젯의 Signing Team, 번들 ID, App Group `group.com.sundaynighttt.codextime`, Keychain Sharing을 자신의 팀에 맞게 함께 설정합니다. 별도 CloudKit 컨테이너는 필요하지 않습니다.

저장소 루트에서 시뮬레이터 빌드·단위 테스트를 실행할 수 있습니다.

```bash
./ios/scripts/test-ios.sh
```

## 개인정보와 서비스 경계

Codex 토큰은 동기화되지 않는 기기 전용 Keychain에 저장하고 서명된 앱과 위젯만 공유합니다. 인증 ID 토큰에 계정 정보가 포함될 수 있으며 실제 Codex 인증·사용량 요청은 OpenAI에 직접 전달됩니다. 웹 로그인·페이지 열기는 해당 공급자와 로그인 제공자로 직접 전달됩니다. 앱은 웹 세션을 내보내지 않고 명시적 수동 확인의 숫자·한도·시각만 로컬에 저장합니다.

비공식 앱이며 공개 소스·로그인 성공이 공급자의 타사 이용 허가나 App Store 승인을 증명하지 않습니다. [개인정보 처리방침](../docs/privacy-policy.md)을 확인하고 토큰·계정 응답·실제 수치를 공개 이슈에 첨부하지 마세요.
