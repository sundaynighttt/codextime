CodexTime 시작하기

  1. 설치: DMG의 Codex Usage Monitor 앱을 Applications 폴더로 옮긴 뒤 실행합니다.
  2. 계정 연결: 간편 설정에서 사용할 서비스를 선택하고 기존 계정 연결을 누릅니다. 처음 한 번 조회 동의와 필요한 macOS 권한을 허용해 주세요.
  3. 로그인: 로그인이 필요하면 로그인하기를 누릅니다. Codex·Claude는 공식 로그인 완료 후 앱이 연결을 확인합니다. Grok은 열린 Cursor에서 로그인한 뒤 간편 설정으로 돌아오세요.
  4. Grok 확인: 웹의 사용률과 리셋 시각을 대조한 뒤 웹 값과 일치함 · 자동 갱신을 누릅니다.
  5. 완료: 연결 완료를 확인하고 설정 완료를 누릅니다. 다음 실행부터 연결된 서비스가 자동 갱신됩니다.

필요한 공식 앱이나 CLI가 없으면 앱의 ‘설치 안내’를 이용하세요. 로그인과 macOS 권한 승인은 본인이 진행합니다. 로그인 만료 시 앱에서 다시 로그인할 수 있습니다.
