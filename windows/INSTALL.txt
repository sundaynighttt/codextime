CodexTime Windows 0.4.0 후보 설치
================================

현재 소스 후보의 안내입니다. 기존 공개 v0.3.1 ZIP은 Codex 전용입니다.
새 후보의 공개 배포와 실물 Windows 실계정 검증은 별도 확인합니다.

필요한 환경
- Windows 10 또는 11 (64비트)
- 사용할 서비스의 공식 앱/CLI와 본인 구독 계정
- Codex: Codex CLI, Claude: Claude Code, Grok: Cursor
- 별도 API 키나 켜져 있는 Mac은 필요하지 않습니다.

설치
1. 검증된 ZIP의 압축을 풉니다.
2. 해당 폴더에서 PowerShell을 엽니다.
3. 다음 명령을 실행합니다.

   powershell -ExecutionPolicy Bypass -File .\install.ps1 -EnableStartup

설치 위치
   %LOCALAPPDATA%\CodexUsageMonitor\CodexTime.exe

계정 연결
1. 첫 실행의 계정 설정에서 사용할 서비스를 선택합니다.
2. Codex/Claude는 공식 CLI 로그인을 직접 완료합니다.
3. Claude/Grok은 앱의 사용량 조회 동의를 허용합니다.
4. Grok은 Cursor에서 같은 본인 계정으로 로그인하고 첫 조회 결과를
   Grok 웹의 사용률/리셋과 비교한 뒤 자동 갱신을 켭니다.

세 로고와 잔여율은 기본으로 모두 표시됩니다. 서비스별 표시를 끄면
진행 중 조회가 취소되고 다음 조회도 중지됩니다. 모두 끄면 '사용량'
진입점이 남습니다. 리셋 시간 표시는 설정에서 선택해 켤 수 있습니다.
기본 10분 갱신이며 조회 실패/20분 지난 값은 이전 값으로 구분합니다.
작업표시줄 표시와 우상단 미니 위젯 사이를 전환할 수 있습니다.

Claude는 기본 ~/.claude/.credentials.json, Grok은 기본 Cursor 저장소의
단일 토큰만 앱 동의 후 읽습니다. Grok은 기존 DB/WAL/SHM과 고정 SQLite
조건을 만족하지 않으면 연결하지 않습니다. 인증 파일, 토큰, 쿠키를
이슈나 채팅에 첨부하지 마세요. 앱은 원본 인증정보를 수정하지 않습니다.

Windows 실행 파일/설치 스크립트는 코드 서명되지 않았습니다.
배포 ZIP의 SHA256SUMS.txt와 공개 소스를 함께 확인하세요.
계정별 인터페이스 지원과 실제 실행 결과는 환경에 따라 다를 수 있습니다.
