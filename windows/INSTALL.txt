CodexTime for Windows
=====================

Requirements:
- Windows 10 or 11
- Codex CLI installed and signed in

Install:
1. Extract this ZIP file.
2. Open Windows PowerShell in the extracted folder.
3. Run:

   powershell -ExecutionPolicy Bypass -File .\install.ps1 -EnableStartup

CodexTime is installed at:

   %LOCALAPPDATA%\CodexUsageMonitor\CodexTime.exe

The default view is a compact label beside the notification area. Right-click
the label or tray icon to switch to the draggable top-right mini widget.

Click the label or widget for details. Right-click for refresh, display mode,
startup, or exit.
