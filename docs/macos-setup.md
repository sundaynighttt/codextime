# macOS 설치와 간편 설정

**v0.3.1 (2026101907) 기준 사용법입니다.** macOS 13 이상, Apple Silicon·Intel을 지원합니다. [설치 파일과 체크섬](https://github.com/sundaynighttt/codextime/releases/tag/v0.3.1) · [macOS DMG](https://github.com/sundaynighttt/codextime/releases/download/v0.3.1/CodexTime-macOS-0.3.1.dmg)

v0.3.0 사용자는 [이전 버전 안내](https://github.com/sundaynighttt/codextime/blob/v0.3.0/docs/macos-setup.md)를 참고하거나 최신 DMG로 업데이트하세요.

## 1. 설치 또는 업데이트

1. **CodexTime-macOS-0.3.1.dmg**를 다운로드해 엽니다. DMG 안의 **시작하기.html**에서도 기본 사용법을 볼 수 있습니다.
2. **Codex Usage Monitor** 앱을 **Applications** 폴더로 옮깁니다. 업데이트라면 실행 중인 기존 앱을 메뉴 막대의 **종료**로 닫고 같은 위치의 앱을 대치합니다.
3. Applications의 앱을 실행합니다. **CodexTime 간편 설정** 창이 열립니다. 다시 열려면 메뉴 막대에서 **간편 설정 및 계정 연결…**을 선택하거나 앱을 다시 엽니다.

기존 연결 설정은 이 Mac에 유지됩니다. 업데이트 후 macOS가 Keychain 접근을 다시 확인하면 요청한 앱과 항목을 확인하고 허용하세요. 앱과 DMG는 Developer ID로 서명하고 Apple 공증을 거칩니다.

## 2. 사용할 서비스 선택

사용할 서비스의 **메뉴 막대에 표시**를 선택합니다. 세 서비스를 모두 연결할 필요는 없습니다. 선택을 끄면 표시와 자동·수동 조회가 멈춥니다. 전부 끄면 다시 선택할 수 있는 **사용량** 메뉴가 남습니다.

이미 공식 앱·CLI에 로그인했다면 **기존 계정 연결**을 먼저 누릅니다. 최초 연결 때 사용량 조회 설명에 동의하고 필요한 macOS 권한을 허용합니다. 연결이 성공하면 **연결 완료**와 실제 사용량이 표시됩니다.

## 3. 로그인하기

### Codex

- 설치된 ChatGPT/Codex 앱의 내장 CLI 또는 [공식 Codex CLI](https://github.com/openai/codex#installation)를 사용합니다. 지원하는 내장 CLI가 있으면 별도 CLI 설치가 필요하지 않을 수 있습니다.
- **로그인하기**를 누르고 열린 공식 브라우저 화면에서 본인의 ChatGPT 계정으로 로그인합니다. 완료 후 앱이 사용량을 다시 조회합니다.
- 필요한 CLI를 찾지 못하면 **설치 안내**가 열립니다. 설치한 뒤 **기존 계정 연결**을 누르세요.

별도 OpenAI API 키는 필요하지 않습니다. Finder에서 실행해도 지원하는 내장 CLI·기본 설치 위치·nvm 설치를 찾습니다. 앱은 Codex 인증 파일을 직접 읽지 않고 공식 CLI의 사용량 응답을 사용합니다.

### Claude

1. [Claude Code](https://code.claude.com/docs/en/setup)가 설치되어 있어야 합니다. Claude Desktop 로그인과 별개입니다.
2. **로그인하기**를 누르고 본인의 Claude 구독 계정으로 공식 로그인을 완료합니다. 터미널 명령을 직접 입력할 필요가 없습니다.
3. 로그인 완료 후 사용량 연결을 자동 확인합니다. 최초 연결의 **사용량 조회 허용** 설명과 macOS Keychain 확인창에서 요청 대상을 확인한 뒤 허용하세요.

이미 Claude Code에 로그인했다면 **기존 계정 연결**로 시작해도 됩니다. 앱은 기본 Claude Code Keychain 항목을 앱 메모리에서 사용하며 연결 동의 전에는 접근하지 않습니다. 백그라운드 갱신은 OS 확인창을 띄우지 않습니다. 권한을 거부했으면 **기존 계정 연결**로 다시 요청할 수 있습니다.

### Grok — Cursor 로그인과 웹 확인

이 연결은 Cursor의 로그인 항목 하나로 공유 사용량을 조회합니다. 계정·플랜에 따라 Grok 웹의 한도와 다를 수 있으므로 처음 연결할 때 대조가 필요합니다.

1. **로그인하기**를 누르면 Cursor가 열립니다. Cursor가 없으면 공식 설치 페이지가 열립니다.
2. Cursor 설정의 **General → Sign In**에서 **Grok과 같은 구독 계정**으로 로그인합니다.
3. 간편 설정 창으로 돌아오면 연결을 다시 확인합니다. 이미 로그인했다면 **기존 계정 연결**을 눌러도 됩니다. 최초 연결 때 **사용량 조회 허용** 설명에 동의합니다.
4. **웹 사용량 열기**에서 같은 계정의 **사용률과 리셋 시각**을 확인합니다. 앱은 남은 비율을 내림하므로 웹의 정수 사용률에서 계산한 값과 1% 차이가 날 수 있습니다.
5. 일치하면 **웹 값과 일치함 · 자동 갱신** → **일치함 · 10분 갱신 시작**을 누릅니다.

값이나 기간이 다르거나 확인할 수 없으면 **연결 해제**합니다. 웹 확인 전에는 자동 갱신이 꺼져 있습니다. 새 Grok 로그인을 시작하거나 계정을 바꾸면 웹 확인을 다시 진행합니다.

## 4. 설정 완료와 평소 사용

- 선택한 서비스가 모두 연결되면 상단에 **설정이 완료됐습니다**가 표시됩니다. **설정 완료**를 눌러 창을 닫습니다. 일부 서비스는 **나중에 설정**할 수 있습니다.
- 부팅 후에도 사용하려면 하단의 **로그인 시 자동 실행**을 선택합니다. 메뉴 막대에서도 변경할 수 있습니다.
- 연결된 서비스는 **10분마다** 독립적으로 갱신됩니다. **새로고침**으로 바로 확인할 수 있습니다.
- `0%`는 조회한 한도의 잔여량이 0%라는 뜻입니다. `—`는 미연결·미확인이고, `*`는 20분 경과 또는 조회 실패로 남은 이전 값입니다.
- 기본 메뉴 막대 값은 가장 적게 남은 공통 한도입니다. Claude의 단기 한도가 리셋되면 주간 한도가 대신 표시될 수 있습니다. 메뉴에서 한도별 상세 내용을 확인할 수 있습니다.
- 창을 닫거나 앱을 다시 실행해도 이 Mac의 연결 설정과 동의는 유지됩니다.

## 문제가 생겼을 때

| 화면 또는 상황 | 할 일 |
| --- | --- |
| 설치 안내 | 해당 공식 앱·CLI를 설치한 뒤 **기존 계정 연결**을 누릅니다. |
| 로그인 필요·로그인 만료 | **로그인하기**에서 공식 로그인을 다시 완료합니다. 완료 후 실제 사용량 조회까지 확인하세요. |
| OS 권한 확인 중 | macOS Keychain 확인창에서 요청 대상을 확인하고 직접 허용합니다. |
| 로그인 대기·취소 | 공식 로그인을 완료하거나 **로그인 취소**로 중단합니다. 로그인 대기는 최대 10분이며 이후 다시 시작할 수 있습니다. |
| 조회 실패·시간 초과 | 네트워크와 공식 앱·CLI 로그인을 확인한 뒤 **기존 계정 연결** 또는 **새로고침**을 누릅니다. |
| Grok 웹 대조 대기 | 같은 계정의 사용률·리셋을 확인한 뒤 일치할 때만 자동 갱신을 시작합니다. |
| 자동 실행 설정 실패 | Applications에 앱을 설치하고 macOS 시스템 설정의 로그인 항목을 확인합니다. |

## 계정 변경과 연결 해제

Claude·Grok 계정을 바꾸기 전에 앱에서 **연결 해제**합니다. 각 공식 앱·CLI에서 새 본인 계정으로 로그인하고 다시 연결하세요. Grok은 웹 대조도 다시 완료합니다. Codex 계정을 바꾼 경우 공식 앱·CLI의 계정 변경 후 **새로고침**으로 확인합니다.

연결 해제는 앱의 연결 상태·동의·메모리 캐시를 지웁니다. 공식 앱·CLI의 원본 인증정보를 삭제하거나 외부 계정을 로그아웃하지 않습니다. 잠시 사용하지 않을 때는 표시 선택만 꺼도 조회가 중지됩니다.

## 지원 범위와 개인정보

로그인과 OS 권한 승인은 본인이 완료합니다. 앱은 로그인 CLI의 인증 출력을 캡처하지 않고 토큰을 별도 저장·내보내기하지 않습니다. 자동 토큰 갱신이나 쿠키·대화 원문 수집을 하지 않습니다. 개발자 계정·인증정보·사용량 캐시는 배포 파일에 포함하지 않습니다.

서비스 제공자의 내부 사용량 인터페이스는 변경되거나 계정·구독 조건에 따라 중단될 수 있습니다. API 결제 잔액·추가 사용량·제품별 비중을 구독 공통 잔여율로 표시하지 않습니다.
