# macOS 설치와 본인 계정 연결

이 안내의 새 동기화 절은 **macOS 0.3.1(2026101907)·iPhone 1.0(12) 후보** 기준입니다. 실제 배포·설치·CloudKit 연결 검증 여부는 [README](../README.md)와 릴리스 기록을 먼저 확인하세요. 문서에 후보가 기재됐다는 사실만으로 다운로드·연결이 완료된 것은 아닙니다.

기존 공개 [v0.3.0 DMG](https://github.com/sundaynighttt/codextime/releases/download/v0.3.0/CodexTime-macOS-0.3.0.dmg)·[릴리스와 체크섬](https://github.com/sundaynighttt/codextime/releases/tag/v0.3.0)은 macOS 13 이상, Intel·Apple Silicon Universal 앱이며 Developer ID 서명과 앱·DMG 공증을 완료한 이전 버전입니다. **0.3.0에는 iCloud 동기화가 없으며, 과거 Claude 연결 안내는 더 이상 권장하지 않습니다. 이전 버전에서는 Claude 연결을 해제하세요.**

## 설치

1. 공개 릴리스에서 버전과 체크섬·서명 안내를 확인하고 macOS DMG를 엽니다.
2. **Codex Usage Monitor**를 **Applications**로 옮긴 뒤 실행합니다.
3. 첫 실행의 **계정 연결 및 표시** 창에서 사용할 서비스를 설정합니다. 창을 닫았으면 메뉴 막대의 **계정 연결 및 표시 설정…**으로 다시 엽니다.

앱에 개발자의 계정·토큰·사용량 캐시는 포함되지 않습니다. 각 서비스의 공식 앱·CLI에서 본인 계정을 사용하며, 세 서비스를 모두 사용할 필요는 없습니다.

## Codex

1. [공식 Codex CLI](https://github.com/openai/codex#installation)를 설치합니다.
2. 터미널에서 `codex login`을 실행해 본인의 ChatGPT 계정으로 로그인합니다.
3. 설정 창의 Codex **새로고침**을 누릅니다.

CodexTime은 CLI가 제공하는 사용량만 요청하며 Codex 인증 파일을 직접 읽지 않습니다. 계정을 바꾼 경우 공식 CLI에서 로그인 계정을 확인한 뒤 다시 새로고침합니다. iPhone Codex는 별도로 OpenAI 공식 기기 로그인과 직접 조회를 사용하며 Mac 동기화가 필요하지 않습니다.

## Claude — 자동 연결 중지

새 후보는 Claude Code Keychain·OAuth 사용량 조회를 시작하지 않고 `—`와 제한 상태를 표시합니다. Anthropic의 [인증 규정](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)에 따라 현재 경로를 중지한 것이며, Mac 또는 iPhone에 새 로그인·토큰 붙여넣기를 요구하지 않습니다. 본인 잔여량은 공식 [Claude 사용량 페이지](https://claude.ai/settings/usage)에서 확인하세요. 과거 앱 접근 허용이나 조회 성공이 공급자의 타사 인증 이용 허가를 뜻하지 않습니다.

## Grok — Cursor 연결과 웹 대조

이 연결은 Cursor의 로그인 항목 하나로 고정 사용량 RPC를 조회하는 조건부 지원입니다. 모든 Grok 계정·플랜에서 같은 한도를 반환한다고 보장하지 않습니다.

1. Cursor 앱에서 **본인의 Grok과 같은 구독 계정**으로 로그인합니다.
2. 설정 창에서 **Cursor로 연결…**을 선택하고 앱의 **사용량 조회 허용** 설명에 동의합니다.
3. 조회가 성공하면 **웹 사용량 열기**로 [본인의 Grok 사용량 화면](https://grok.com/?_s=usage)을 엽니다.
4. 같은 계정·구독 기간의 **사용률과 리셋 시각**을 확인합니다. 앱은 남은 비율을 내림해 표시하므로 웹의 정수 표시와 반올림 차이가 있을 수 있습니다.
5. 일치할 때만 **웹 값과 일치함 · 자동 갱신**을 누르고 확인창의 **일치함 · 10분 갱신 시작**을 선택합니다.

웹 대조 전에는 자동 조회가 꺼져 있습니다. 값·기간이 다르거나 확인되지 않으면 자동 갱신을 켜지 말고 **연결 해제**합니다. 앱은 다른 DB 키·team·쿠키·기존 Grok Bot Keychain·refresh token을 찾아 대체하지 않습니다. 로그인 문제는 Cursor의 공식 로그인에서 해결한 뒤 다시 연결합니다.

## 본인 iCloud로 iPhone에 Grok 결과 보내기

이 기능은 지원·서명·CloudKit 설정이 완료된 새 빌드에서만 사용할 수 있습니다. Mac과 iPhone에서 같은 본인 Apple 계정으로 iCloud에 로그인하고, 각 기기의 **iCloud 동기화**를 직접 켭니다. 기본값은 꺼짐이며, Mac의 Grok 연결과 웹 대조를 먼저 마쳐야 합니다.

보내는 정보는 서비스 구분·잔여율·리셋 시각·실제 조회 시각·고정 상태뿐입니다. 본인 비공개 CloudKit 저장소를 사용하고 비밀번호·토큰·쿠키·이메일·계정 ID·기기 이름·원시 응답·Claude 실제 수치는 전송하지 않습니다. iPhone은 이 값을 3열 카드와 위젯에 표시하며 Claude는 제한 상태로 남습니다.

최신 Grok 조회에는 **깨어 있는 Mac, 실행 중인 앱, Grok 표시와 연결, 네트워크**가 필요합니다. Mac 조회는 10분 간격이며 클라우드 전달·위젯 실행은 OS가 결정합니다. Mac이 꺼지면 마지막 값과 조회 시각을 보여주고 20분 뒤에는 오래된 정보로 표시합니다. 동기화 오류와 실제 잔여량 0%는 구분합니다.

- **Mac에서 동기화 체크를 끄거나 ‘끄고 iCloud 값 삭제’를 선택**하면 이 Mac의 전송·로컬 캐시를 중지·정리하고 본인 iCloud 레코드 삭제도 요청합니다.
- **iPhone의 ‘이 iPhone에서 동기화 해제’**는 이 기기의 수신·로컬 캐시만 정리합니다. iPhone에서 원격 데이터도 지우려면 별도 **iCloud 동기화 데이터 삭제**를 선택합니다.
- 어느 기기든 Apple의 삭제 성공 응답 후에만 완료 처리합니다. 오프라인 등으로 응답을 받지 못하면 삭제 대기로 남으며, 네트워크 복구 후 재시도해야 합니다. 삭제 완료 표시를 확인하세요.
- 다른 Mac의 동기화가 켜져 있으면 다시 업로드할 수 있으므로 전체 중단에는 각 Mac에서도 꺼야 합니다.
- iCloud 로그아웃·계정 변경 시 로컬 캐시와 동기화 선택을 지웁니다. 새 계정에서는 다시 켜야 합니다. 이전 계정의 클라우드 데이터를 지우려면 로그아웃 전에 삭제를 완료하세요.

## 서비스 표시와 새로고침

- 기본은 Codex·Grok·Claude 모두 표시입니다. Claude 칸이 보인다는 사실이 실제 연결을 뜻하지 않습니다.
- 메뉴나 설정의 **메뉴 막대에 표시** 체크를 끄면 해당 서비스가 숨겨지고 자동·수동·잠자기 복귀 조회도 중지됩니다. 마지막 성공 값은 앱 메모리에 남을 수 있습니다. 동기화 중이면 Grok은 수치 없는 일시 중지 상태로 전달하고, 동기화가 중단돼 전달하지 못한 이전 값은 조회 시각과 함께 오래된 값으로 구분합니다.
- 다시 켜면 사용자가 연결한 허용 범위에서 조회를 재개합니다. 모두 숨겨도 메뉴 막대의 **사용량** 항목으로 다시 켤 수 있습니다.
- 연결된 표시 서비스는 10분마다 각각 갱신합니다. `—`는 미연결·미확인·차단, `*`는 마지막 성공 후 20분 경과 또는 재조회 실패로 남은 이전 값입니다.

## 계정 변경과 연결 해제

Grok 계정을 바꾸기 전에 동기화를 끄고 앱 설정에서 **연결 해제**합니다. 앱은 진행 중 조회와 해당 연결·검증 상태·메모리 캐시를 정리하며 Cursor의 원본 토큰을 삭제하거나 공식 앱을 로그아웃하지 않습니다. 공식 앱에서 새 본인 계정으로 로그인한 뒤 다시 연결하고 웹 대조를 다시 완료하세요. Mac에서 동기화를 끌 때 요청한 iCloud 삭제가 완료됐는지도 확인합니다.

서비스를 잠시 사용하지 않을 때는 표시 체크만 꺼도 조회가 중지됩니다. iCloud 데이터 보관·삭제와 공식 앱의 로그인 해제는 각각 별도 동작입니다.

## 지원 범위와 개인정보

내부 사용량 인터페이스는 제공자 변경이나 계정·구독 조건에 따라 중단될 수 있습니다. API 결제 잔액·추가 사용량·제품별 비중을 구독 공통 잔여율로 만들지 않습니다. 인증정보는 별도 저장·갱신·내보내기를 하지 않으며 iCloud에도 보내지 않습니다. 동기화에 동의한 최소 사용량 필드는 Apple에 저장됩니다. 쿠키·대화 원문을 읽지 않으며 배포 파일·문서·진단에 토큰과 실제 계정 응답을 넣지 않습니다.

## 직접 빌드·서명

로컬 ad-hoc 빌드는 iCloud 권한을 넣지 않고 동기화를 비활성화합니다. 정식 Developer ID 빌드에는 같은 team·Mac App ID·CloudKit 컨테이너와 Production 환경을 허용하는 Developer ID 배포 프로필이 필요합니다. `CODEXTIME_PROVISIONING_PROFILE`에 정확한 파일 경로를 지정하고 기존 `CODEXTIME_SIGN_IDENTITY`와 함께 빌드하세요. 스크립트가 권한·만료·서명 인증서 일치를 검사하며 개발용 프로필이나 누락된 프로필은 거부합니다.

GitHub 릴리스 워크플로는 `MACOS_PROVISIONING_PROFILE_BASE64` 설정을 요구하도록 준비했습니다. 이번 작업은 이 값을 GitHub에 등록하지 않았고 배포용 프로필 확보·운영 스키마 배포·실제 송수신 검증이 남아 있습니다. 프로필이나 인증서 원문을 이슈·로그에 첨부하지 마세요.
