# macOS 설치와 본인 계정 연결

이 안내는 **v0.3.0 (2026101906) 공개 버전** 기준입니다. [macOS DMG 다운로드](https://github.com/sundaynighttt/codextime/releases/download/v0.3.0/CodexTime-macOS-0.3.0.dmg) · [릴리스와 체크섬](https://github.com/sundaynighttt/codextime/releases/tag/v0.3.0). macOS 13 이상, Intel·Apple Silicon Universal 앱이며 Developer ID 서명과 앱·DMG Apple 공증을 완료했습니다.

## 설치

### 간편 설정 개선판

아래 흐름은 다음 macOS 개선판에 포함되는 변경입니다. 현재 공개된 v0.3.0의 수동 설치·로그인 절차는 아래 서비스별 안내를 참고하세요.

간편 설정 개선판에서는 첫 실행의 **CodexTime 간편 설정** 창에서 필요한 단계만 진행합니다.

1. 사용할 서비스의 **메뉴 막대에 표시**를 선택합니다.
2. 이미 로그인했다면 **기존 계정 연결**을 누릅니다. 최초 연결 때만 앱의 사용량 조회 동의와 필요한 macOS 권한을 허용합니다.
3. 로그인이 없거나 만료됐으면 **로그인하기**를 누릅니다. Codex와 Claude는 설치된 공식 CLI의 브라우저 로그인 절차가 열리고, 완료 후 앱이 사용량 연결을 다시 확인합니다. 터미널 명령을 직접 입력할 필요가 없습니다. 대기 중에는 **로그인 취소**로 중단할 수 있습니다.
4. Grok의 로그인 버튼은 Cursor를 엽니다. Cursor 설정의 **General → Sign In**에서 Grok과 같은 계정으로 로그인한 뒤 이 창으로 돌아오면 연결을 다시 확인합니다. **웹 사용량 열기**에서 사용률·리셋을 확인하고 **웹 값과 일치함 · 자동 갱신**을 눌러 마칩니다.
5. 상단에 선택한 서비스의 연결 완료가 표시되면 **설정 완료**를 누릅니다. 필요하면 하단의 **로그인 시 자동 실행**도 선택할 수 있습니다.

필요한 공식 앱·CLI가 없으면 **설치 안내**에서 공식 설치 페이지를 엽니다. Codex는 설치된 ChatGPT/Codex 앱의 내장 CLI도 찾으므로 별도 CLI 설치가 필요하지 않을 수 있습니다. 로그인 완료는 CLI 종료만으로 판정하지 않고 실제 사용량 응답까지 확인합니다. 로그인과 OS 권한 승인은 사용자 본인이 완료합니다.

연결 설정과 동의는 이 Mac에 유지됩니다. 정상 연결된 서비스에는 재설치·로그인 안내를 반복해서 표시하지 않습니다. 연결 해제 후에는 사용량 조회 동의를 다시 받으며, Grok을 새로 로그인할 때는 웹 대조도 다시 진행합니다. 앱은 CLI의 인증 출력이나 토큰을 캡처하지 않습니다.

1. 공개가 완료된 macOS DMG를 엽니다.
2. **Codex Usage Monitor**를 **Applications**로 옮긴 뒤 실행합니다.
3. 첫 실행의 **계정 연결 및 표시** 창에서 사용할 서비스를 설정합니다. 창을 닫았으면 메뉴 막대의 **계정 연결 및 표시 설정…**으로 다시 엽니다.

앱에 개발자의 계정·토큰·사용량 캐시는 포함되지 않습니다. 각 서비스의 공식 앱·CLI에서 본인 계정으로 로그인해야 하며, 세 서비스를 모두 사용할 필요는 없습니다.

## Codex

1. [공식 Codex CLI](https://github.com/openai/codex#installation)를 설치합니다.
2. 터미널에서 `codex login`을 실행해 본인의 ChatGPT 계정으로 로그인합니다.
3. 설정 창의 Codex **새로고침**을 누릅니다.

CodexTime은 CLI가 제공하는 사용량만 요청하며 Codex 인증 파일을 직접 읽지 않습니다. 계정을 바꾼 경우 공식 CLI에서 로그인 계정을 확인한 뒤 다시 새로고침합니다.

## Claude

1. [공식 Claude Code 안내](https://code.claude.com/docs/en/setup)에 따라 CLI를 설치합니다.
2. 터미널에서 `claude auth login --claudeai`를 실행하고 본인의 Claude 구독 계정으로 로그인합니다. Claude Desktop 로그인과 별개입니다.
3. 설정 창에서 **Claude 연결…**을 누르고 앱의 **사용량 조회 허용** 설명에 동의합니다.
4. macOS Keychain 확인창이 나타나면 접근 대상을 확인해 직접 허용합니다. OS 암호나 로그인 정보는 공식 절차에서 직접 입력합니다.

앱은 기본 Claude Code Keychain 항목으로 사용량만 읽습니다. 앱 연결 동의 전에는 이 항목이나 사용량 HTTP에 접근하지 않으며, 연결 후 백그라운드 조회는 OS 확인창을 띄우지 않습니다. 취소·거부했다면 다시 사용할 때 **Claude 연결…**을 명시적으로 선택합니다. 토큰이 만료되면 공식 Claude Code에서 로그인한 뒤 앱을 다시 연결합니다.

## Grok — Cursor 연결과 웹 대조

이 연결은 Cursor의 로그인 항목 하나로 고정 사용량 RPC를 조회하는 조건부 지원입니다. 모든 Grok 계정·플랜에서 같은 한도를 반환한다고 보장하지 않습니다.

1. Cursor 앱에서 **본인의 Grok과 같은 구독 계정**으로 로그인합니다.
2. 설정 창에서 **Cursor로 연결…**을 선택하고 앱의 **사용량 조회 허용** 설명에 동의합니다.
3. 조회가 성공하면 **웹 사용량 열기**로 [본인의 Grok 사용량 화면](https://grok.com/?_s=usage)을 엽니다.
4. 같은 계정·구독 기간의 **사용률과 리셋 시각**을 확인합니다. 앱은 남은 비율을 내림해 표시하므로 웹의 정수 표시와 반올림 차이가 있을 수 있습니다.
5. 일치할 때만 **웹 값과 일치함 · 자동 갱신**을 누르고 확인창의 **일치함 · 10분 갱신 시작**을 선택합니다.

웹 대조 전에는 자동 조회가 꺼져 있습니다. 값·기간이 다르거나 확인되지 않으면 자동 갱신을 켜지 말고 **연결 해제**합니다. 앱은 다른 DB 키·team·쿠키·기존 Grok Bot Keychain·refresh token을 찾아 대체하지 않습니다. 로그인 문제는 Cursor의 공식 로그인에서 해결한 뒤 다시 연결합니다.

## 서비스 표시와 새로고침

- 기본은 Codex·Grok·Claude 모두 표시입니다.
- 메뉴나 설정의 **메뉴 막대에 표시** 체크를 끄면 해당 서비스가 숨겨지고 자동·수동·잠자기 복귀 조회도 중지됩니다. 마지막 성공 값은 앱 메모리에만 남습니다.
- 다시 켜면 사용자가 연결한 범위에서 조회를 재개합니다. 모두 숨겨도 메뉴 막대의 **사용량** 항목으로 다시 켤 수 있습니다.
- 연결된 표시 서비스는 10분마다 각각 갱신합니다. `—`는 미연결·미확인, `*`는 마지막 성공 후 20분 경과 또는 재조회 실패로 남은 이전 값입니다.

## 계정 변경과 연결 해제

Claude·Grok의 계정을 바꾸기 전에 앱 설정에서 **연결 해제**합니다. 앱은 진행 중 조회를 정리하고 해당 연결 플래그·메모리 캐시를 지웁니다. 공식 앱·CLI의 로그인 토큰을 삭제하거나 외부 계정을 로그아웃하지 않습니다. 공식 앱·CLI에서 새 본인 계정으로 로그인한 뒤 다시 연결하고, Grok은 웹 대조도 다시 완료합니다.

서비스를 잠시 사용하지 않을 때는 표시 체크만 꺼도 조회가 중지됩니다. 앱 연결과 원본 로그인을 모두 해제하려면 각각의 공식 앱·CLI에서 별도로 처리합니다.

## 지원 범위와 개인정보

내부 사용량 인터페이스는 제공자 변경이나 계정·구독 조건에 따라 중단될 수 있습니다. API 결제 잔액·추가 사용량·제품별 비중을 구독 공통 잔여율로 만들지 않습니다. 인증정보는 앱 메모리에서만 사용하고 별도 저장·갱신·내보내기를 하지 않습니다. 쿠키·대화 원문을 읽지 않으며 배포 파일·문서·진단에 토큰과 실제 계정 응답을 넣지 않습니다.
