# Windows 설치와 세 서비스 연결

현재 **Windows 0.4.0 소스 후보**의 안내입니다. 기존 공개 **v0.3.1 ZIP은 Codex 전용**이며 새 버전의 공개 다운로드와 검증 결과는 [후보 기록](releases/2026-10-20-windows-v0.4.0.md)을 따릅니다. 실물 Windows의 본인 계정 로그인·사용량·재시작 검증은 아직 확인되지 않았습니다. Mac v0.3.1과 iPhone TestFlight 1.0(16)은 별도 배포본입니다.

## 설치와 업데이트

Windows 10/11 64비트에서 사용합니다. 새 후보 ZIP을 직접 빌드하거나 검증된 새 배포본을 받은 뒤 압축을 풀고 같은 폴더의 PowerShell에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -EnableStartup
```

설치 위치는 `%LOCALAPPDATA%\CodexUsageMonitor`입니다. 업데이트는 실행 중 앱을 종료한 뒤 새 ZIP의 설치 스크립트를 실행합니다. 표시·연결 동의 같은 기존 비민감 설정은 유지합니다. Windows 실행 파일과 스크립트는 코드 서명되지 않았습니다. 공개 배포본에서는 함께 제공하는 `SHA256SUMS.txt`를 확인하세요.

## 첫 연결

1. 첫 실행의 계정 설정에서 사용할 서비스를 고릅니다. 이후에도 표시의 오른쪽 클릭 메뉴에서 계정 설정을 다시 엽니다.
2. **Codex:** 공식 Codex CLI를 설치하고 설정의 로그인 동작으로 본인 계정 로그인을 완료합니다. 기존 로그인으로 `codex app-server`가 사용량 메타데이터만 요청합니다.
3. **Claude:** 공식 Claude Code의 구독 계정 로그인을 직접 완료하고 앱의 사용량 조회에 동의합니다. 기본 Windows Claude Code OAuth 저장소만 지원하며 Claude Desktop 로그인과는 다릅니다. 만료되면 공식 CLI에서 다시 로그인합니다.
4. **Grok:** Cursor를 열어 본인의 같은 계정으로 로그인하고 앱의 사용량 조회에 동의합니다. 첫 조회의 사용률·리셋을 본인 [Grok 웹 사용량](https://grok.com/?_s=usage)과 비교한 뒤 일치할 때 자동 갱신을 시작합니다. 같은 계정·구독 기간인지 확인되지 않거나 값이 다르면 연결을 해제하세요.

추가 서비스의 토큰 자체는 사용량 전용 자격증명이 아닙니다. 앱이 허용된 저장소·고정 요청·응답 필드만 사용하도록 제한합니다. 별도 API 키·모델 호출·Mac·iCloud는 필요하지 않습니다. 내부 사용량 인터페이스가 모든 계정이나 구독을 지원한다고 보장하지 않습니다.

## 표시와 갱신

- **Codex / Grok / Claude** 로고·잔여율이 기본으로 모두 보입니다. 공통 한도 중 가장 적게 남은 잔여율을 내림해 표시하고 모델별·제품별 사용량을 합치지 않습니다.
- 서비스별 표시를 끄면 해당 조회를 취소하고 자동·수동·복귀 조회도 중지합니다. 모두 꺼도 **사용량** 진입점이 남아 다시 켤 수 있습니다.
- 연결된 표시 서비스는 기본 **10분**마다 독립 갱신합니다. 리셋 시간은 기본 꺼짐이며 선택해 표시합니다. 카운트다운은 **1분**마다 표시만 갱신합니다.
- `—`는 미연결·미확인입니다. 조회 실패나 마지막 성공 후 20분 경과 값은 이전 값으로 구분합니다. 한 서비스의 오류가 다른 서비스의 값을 지우지 않습니다.
- 작업표시줄 옆 표시와 우상단 미니 위젯을 전환할 수 있습니다. 상세 화면에서 실제 제공되는 한도·리셋·연결 상태를 확인합니다.

## 인증정보와 보관 범위

Codex는 인증 파일을 앱이 직접 읽지 않습니다. Claude·Grok은 서비스별 앱 동의 후 아래 기본 저장소만 사용합니다.

| 서비스 | 기본 입력 | 사용 범위 |
| --- | --- | --- |
| Claude | `~/.claude/.credentials.json` | `claudeAiOauth.accessToken`과 만료·필요 scope 검증; 고정 Anthropic usage GET |
| Grok | `%APPDATA%\Cursor\User\globalStorage\state.vscdb` | `cursorAuth/accessToken` 한 항목; 고정 Cursor usage POST |

Cursor DB는 고정 SQLite 3.53.4를 사용해 읽기 전용으로 엽니다. 기본 DB와 **이미 존재하는 WAL·SHM 두 파일**의 안전한 로컬 경로·파일 상태를 검증합니다. 둘 중 하나가 없거나 네트워크·reparse point·지원하지 않는 경로이면 중단합니다. 원본 DB·sidecar·인증정보를 생성·복사·수정하거나 다른 키로 대체하지 않습니다. 이 제한 때문에 일반 Cursor 로그인 상태에서도 연결할 수 없는 환경이 있습니다.

토큰·사용량·리셋·마지막 성공 값은 앱 메모리에만 둡니다. 로컬 설정에는 표시·동의·Grok 대조·설정 완료 같은 비민감 값만 저장합니다. 연결 해제는 앱의 허용·메모리 캐시를 지우며 공식 앱·CLI 자격증명이나 외부 계정·구독은 삭제하지 않습니다. 계정 변경 시 **앱 연결 해제 → 공식 로그인 → 앱 재연결 → Grok 재대조** 순서로 진행합니다.

## 연결되지 않을 때

- **CLI 없음·로그인 필요:** 공식 설치·로그인을 완료한 뒤 앱에서 다시 연결합니다. 인증 파일을 편집하거나 토큰을 직접 붙여넣지 않습니다.
- **Claude 인증 만료·권한 없음:** 공식 Claude Code 구독 계정으로 다시 로그인합니다. 앱은 refresh token을 사용하거나 다른 프로필을 탐색하지 않습니다.
- **Grok 저장소 미지원·권한·잠금:** Cursor의 같은 계정 로그인을 확인합니다. DB나 WAL·SHM을 수동으로 만들거나 옮기지 마세요. 앱은 안전한 읽기 조건을 확인할 수 없으면 중단합니다.
- **Grok 웹 값 불일치:** 자동 갱신을 켜지 말고 연결을 해제합니다. Cursor RPC 응답 성공만으로 같은 Grok 구독 잔여량이라고 판단하지 않습니다.
- **이전 값 표시:** 연결 상태·마지막 성공 시각을 확인하고 해당 서비스만 새로고침합니다. 원시 응답·인증정보 없이 고정 상태와 버전만 제보합니다.

삭제하려면 앱을 종료하고 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\CodexUsageMonitor\uninstall.ps1"
```
