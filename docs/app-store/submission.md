## 이번 변경

기존 위젯 제목 옆 갱신 시각·새로고침 정렬(빌드 8)을 유지한다. 누구나 쓸 수 있는 오프라인 예시 모드, 예시/실제 캐시 분리, 앱과 위젯의 예시 표시, 이용 안내·개인정보·지원 링크, 앱 본문의 누적 토큰 표시를 추가했다. 실제 계정의 로그인 및 사용량 요청 경로는 변경하지 않았다.

## 스토어 표현과 심사 경계

- 비공식 읽기 전용 사용량 대시보드이며 OpenAI의 제작·보증을 주장하지 않는다.
- 실제 조회에는 사용자의 ChatGPT 계정이 필요하다. Codex CLI·켜져 있는 Mac·별도 API 키는 필요하지 않다.
- 기본 한도 구간만 표시한다. 모든 구간, 결제 크레딧, 리셋 실행 기능은 없다.
- 위젯은 30분 뒤 갱신을 요청하지만 실제 일정은 iOS가 결정한다.
- 공개 예시 모드는 로그인 없이 작동한다. 심사에만 보이는 숨겨진 경로나 실제 값처럼 꾸민 예시가 아니다.
- 영문 심사 메모에 `예시 데이터로 둘러보기 → 위젯 추가 → 예시 끝내기` 절차, 실제 계정의 OpenAI 외부 기기 인증과 `wham/usage`, `wham/profiles/me` 접근을 설명한다.
- 심사 연락처는 사용자 제공 기존 연락처를 App Store Connect에만 입력한다. 저장소에는 복제하지 않는다.

## 개인정보

[공개 방침](../privacy-policy.md)을 기준으로 작성한다. 앱의 방침 링크는 해당 문서의 고정 커밋 `0405d909da7db6fd58a337e417d336b89e88fee3`을 사용한다.

개발자 자체 서버·광고·추적·분석 SDK는 없다. 실제 연결에서는 외부 제공자에게 계정 인증·사용량 요청과 네트워크 정보가 전달되므로 ‘어떤 데이터도 수집되지 않음’이라고 일괄 답하지 않는다. 보수적으로 사용자 ID, 기타 사용 데이터, 기타 진단 데이터를 앱 기능 목적·사용자 연결·추적 안 함으로 분류한다. 로컬 Keychain에는 인증 토큰, App Group에는 사용량 캐시를 저장한다. 예시 모드는 이러한 외부 요청을 수행하지 않는다.

앱·위젯의 `PrivacyInfo.xcprivacy`는 같은 분류를 사용하고 UserDefaults의 앱 내부·App Group 사용 사유를 선언한다. 실제 연결 해제는 기기의 토큰·캐시만 삭제한다.

## 제출 재개 조건

사용자가 해당 계정 로그인·사용량 조회 방식을 독립 앱에서 이용할 수 있는 권한 근거를 확인하면 콘텐츠 권한을 정확히 설정하고 다시 ‘심사에 추가’를 진행한다. 단순 로그인 성공이나 GitHub 소스 공개를 권한 증거로 대체하지 않는다. [Codex 인증 안내](https://learn.chatgpt.com/docs/auth)는 Codex의 기기 인증 방식을 설명하지만 이 앱의 독립 배포에 대한 별도 허락을 확인해 주지는 않는다. [OpenAI 이용약관](https://openai.com/policies/row-terms-of-use/)에는 자동 데이터 추출 제한이 있으므로, 구체적인 적용·허용 범위를 확인해야 한다. 이는 위반을 확정한 판단이 아니라 권한 확약의 근거가 아직 없다는 경계다.
