# CodexTime 개인정보 처리방침

갱신일: 2026-10-20

CodexTime은 지원하는 서비스의 본인 사용량을 확인하는 비공식 오픈소스 유틸리티입니다. 개발자는 사용자 계정을 운영하지 않으며 광고·추적·분석 SDK나 별도 데이터 수집 서버를 사용하지 않습니다.

이 문서는 **1.0(17) 아이폰 단독 직접 연결의 로컬 후보**와 유지되는 수동 웹 확인의 처리 범위를 설명합니다. Apple에서 처리된 최신 확인본은 **1.0(16)**입니다. 새 후보의 실제 계정 로그인·사용량 권한·인증 갱신·TestFlight 처리·iPhone 위젯 대조는 아직 완료로 기록하지 않습니다. 정확한 상태는 [릴리스 원장](releases/release-ledger.json)을 따릅니다.

## iPhone Codex 직접 연결에서 처리하는 정보

- **인증 정보:** OpenAI의 외부 기기 인증 페이지에서 사용자가 연결을 승인합니다. 앱은 비밀번호를 직접 입력받지 않습니다. 발급된 ID·액세스·갱신 토큰은 iCloud 동기화되지 않는 기기 전용 Keychain에 저장하며, 같은 서명 그룹의 앱과 위젯만 공유합니다. ID 토큰에는 OpenAI가 발급한 계정 관련 정보가 포함될 수 있습니다.
- **계정 식별자:** 사용량 요청을 인증하기 위해 토큰에서 계정 식별자를 읽어 OpenAI에 전송합니다.
- **사용량:** 기본 한도의 남은 비율, 리셋 시각, 마지막 갱신 시각과 제공되는 경우 누적 토큰을 앱과 위젯의 공유 저장소에 캐시합니다. 프로필 응답에서 이름·사진·사용자명은 저장하지 않고 누적 토큰 숫자만 읽습니다. 대화·프롬프트 내용은 요청하지 않습니다.
- **네트워크:** 인증과 사용량 요청은 OpenAI로 직접 전달됩니다. OpenAI는 IP 주소와 요청 등 서비스 제공에 필요한 정보를 처리할 수 있습니다. 외부 지원·소스 페이지를 열면 GitHub의 접속 정보 처리 정책이 적용됩니다.

개발자에게 사용량이나 인증 토큰을 보내지 않습니다. ‘수집 서버가 없다’는 말은 외부 인증·호스팅 제공자가 네트워크 정보를 전혀 처리하지 않는다는 뜻이 아닙니다.

## iPhone Grok 직접 연결 — 1.0(17) 로컬 후보

- **인증:** 사용자가 앱에서 연결을 시작하면 xAI의 기기 인증 페이지에서 직접 승인합니다. OpenClaw 공개 문서에 소개된 공유 공개 OAuth 클라이언트를 사용하므로 승인 화면에 **Grok Build**가 표시될 수 있습니다. CodexTime이 xAI의 별도 등록·승인 앱이라는 뜻은 아닙니다. 후보의 요청 범위는 `openid offline_access grok-cli:access`입니다. 인증 코드를 발급받을 수 있음은 확인했지만 이 범위로 실제 계정의 구독 사용량을 읽을 수 있는지는 별도 확인이 필요합니다.
- **보관:** 이 연결에서 새로 발급된 액세스·갱신 토큰과 만료 시각은 CodexTime 전용의 동기화되지 않는 기기 전용 Keychain 항목에 보관하며 같은 서명 그룹의 앱과 위젯만 공유합니다. Safari·Cursor·Mac·다른 앱의 쿠키나 인증정보를 가져오지 않습니다. 앱 코드는 ID 토큰·이메일·프로필을 사용량 캐시에 보관하지 않습니다.
- **직접 요청:** 인증 코드는 `auth.x.ai/oauth2/device/code`, 토큰 발급·갱신은 `auth.x.ai/oauth2/token`, 사용량은 고정 `GET https://cli-chat-proxy.grok.com/v1/billing?format=credits`로 직접 요청합니다. 개발자 서버·Mac·PC·iCloud 중계는 없습니다. 메시지·대화·모델 생성 요청을 보내지 않습니다. 제공자는 IP 주소와 인증·사용량 요청에 필요한 정보를 처리할 수 있습니다.
- **사용량과 갱신:** 검증된 사용률·서버가 제공한 주간/월간/미상 기간·리셋 시각·실제 조회 시각만 같은 기기의 App Group에 원자적으로 캐시합니다. 결제 금액·모델별 비중을 구독 잔여율로 바꾸거나 월간을 주간으로 표시하지 않습니다. 앱의 활성 상태 갱신과 위젯 타임라인은 저장된 인증으로 직접 조회할 수 있으나 실제 계정 호환성은 미검증입니다. WidgetKit 실행 시점은 iOS가 결정하므로 고정 주기 갱신을 보장하지 않습니다.
- **실패와 삭제:** 인증 갱신은 앱·위젯 사이에서 직렬화하고 연결 세대를 확인합니다. 갱신 결과가 불확실하면 이전 갱신 토큰을 자동 재사용하지 않고 재연결을 요구합니다. 조회 실패는 같은 연결의 마지막 성공 값과 실제 조회 시각을 유지하며 오래된 값·재연결 필요를 구분합니다. 연결 해제는 이 앱의 토큰·사용량 캐시·수동 웹 기록을 지우고 진행 중 이전 연결의 결과가 다시 저장되지 않도록 합니다. 공급자 계정·구독이나 다른 앱의 로그인을 삭제하지 않습니다.

## iPhone Claude 직접 연결 — 비공식 호환 후보

**이 경로는 Anthropic이 승인한 타사 로그인 연동으로 확인되지 않았습니다.** [공식 인증·자격증명 지침](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)은 자체 앱의 Claude.ai 로그인 제공과 구독 자격증명·세션 토큰의 수집·보관·중개를 제한합니다. [공식 로그인 안내](https://support.claude.com/en/articles/13189465-log-in-to-your-claude-account)는 오픈소스를 포함한 타사 개발자에게 API 키 경로를 안내하고, 특정 타사 도구의 허용은 Anthropic의 재량이라고 설명합니다. 사용량 메타데이터 전용·개인 오픈소스·TestFlight 내부 배포에 대한 명시적 예외나 CodexTime의 허용은 확인하지 못했습니다. 공개 구현 사례와 아래 합성 검증은 공급자의 허가를 증명하지 않습니다. 실제 계정 로그인과 활성 배포 여부는 별도로 판단합니다.

- **후보 인증:** 공개 네이티브 클라이언트 선례의 Claude Code 공개 클라이언트 ID와 PKCE를 사용하는 독립 구현입니다. `https://claude.ai/oauth/authorize`에서 사용자가 직접 승인하고, 정확한 `https://platform.claude.com/oauth/code/callback`의 결과 또는 사용자가 입력한 일회성 `code#state`를 검증하는 후보입니다. PKCE 검증자·상태는 진행 중 앱 메모리에만 두고 앱이 비밀번호·2FA·다른 앱의 세션을 수집하지 않습니다. 요청 범위 `user:profile`의 실제 계정 허용·사용량 권한은 미검증입니다.
- **후보 보관과 요청:** 활성화되어 연결을 완료하는 경우 새로 발급된 액세스·갱신 토큰은 CodexTime의 별도 기기 전용 Keychain 항목에만 보관하고 같은 서명 그룹의 앱·위젯이 공유하도록 설계했습니다. 기존 Claude Code·Claude 앱·브라우저의 인증정보는 읽지 않습니다. 고정 토큰 경로 `https://platform.claude.com/v1/oauth/token`와 사용량 경로 `GET https://api.anthropic.com/api/oauth/usage`만 사용하며 모델·대화 요청이나 개발자·PC·iCloud 중계는 없습니다.
- **사용량과 삭제:** 공통 `five_hour`·`seven_day` 사용률·리셋과 실제 조회 시각만 해석하며 두 한도를 함께 검증하고 함께 캐시하는 후보입니다. 모델별 한도·금액·프로필은 저장하지 않습니다. 직접 연결의 토큰 갱신·오류·연결 세대·삭제 경계는 Grok과 동일하게 분리하며 다른 공급자의 숫자를 복제하지 않습니다. 실제 계정에서 이 경로가 성공하거나 자동 갱신된다는 주장은 아직 하지 않습니다.

## iPhone Grok·Claude 공식 웹의 수동 확인 — 배포본 및 후보의 대체 경로

각 공급자의 공식 웹을 `nonPersistent WKWebView`로 열어 사용자가 직접 로그인하고 사용량 화면의 퍼센트를 수동 확인합니다. **1.0(13)~(15)**는 숫자 의미·한도를 고르고 위치를 탭하는 방식이었습니다. **1.0(16) TestFlight**는 Claude에서 사용자가 **사용량 읽기**를 한 번 누르면 허용된 짧은 표시 라벨을 기기 내에서 해석해 현재 세션과 전체 모델 주간 퍼센트를 구분하는 방식을 추가합니다. Grok은 기존 위치 지정 방식을 유지합니다. Mac·Cursor·iCloud·개발자 서버나 별도 API 키를 사용하지 않습니다. 실제 계정 연결·검증·서명·배포 상태는 [릴리스 원장](releases/release-ledger.json)에서 따로 확인하세요.

- **공식 웹 로그인:** 비밀번호·2FA·SSO 입력은 공식 페이지에서 사용자가 직접 수행합니다. WebKit은 로그인에 필요한 세션을 메모리에서 처리하지만 앱 코드는 쿠키·토큰·비밀번호를 열람·복사·Keychain 저장·기기 간 전송하지 않습니다. 쿠키를 Safari·Mac·다른 앱에서 가져오지 않습니다.
- **세션 유지:** 웹 세션은 앱 실행 중에만 유지합니다. 연결 화면을 닫고 다시 열어도 같은 실행 중에는 유지될 수 있으나 앱 종료나 해당 서비스 연결 해제 뒤에는 다시 로그인해야 합니다. 웹 사이트의 만료·추가 인증 때문에 더 일찍 재로그인이 필요할 수 있습니다.
- **Grok의 위치 지정 확인:** 사용자가 공식 사용량 화면에 숫자가 보임을 확인하고 사용함/남음·주간 한도를 정한 뒤 숫자 위치 읽기를 실행합니다. 읽기 시작 때 선택한 의미·한도를 고정하며 웹 문구로 한도를 자동 선택하지 않습니다. 한 번의 직접 탭은 숫자 읽기에만 사용하고 15초 안에 탭하지 않으면 취소합니다.
- **Claude의 한 번 읽기 — 1.0(16) TestFlight:** 사용자가 **사용량 읽기**를 누를 때만 HTTPS 공식 Claude 호스트의 보이는 사용량 패널을 제한된 DOM 검사로 확인합니다. 정해진 한국어·영어 라벨과 가까운 퍼센트만 기기 내 웹뷰에서 해석해 현재 세션·전체 모델 주간을 구분합니다. 현재 세션과 전체 모델 주간의 두 숫자가 모두 검증돼야 읽기에 성공합니다. 한쪽만 확인되거나 모호하면 전체 읽기를 중단하고 이전 두 숫자·확인 시각을 유지합니다. 검증된 두 퍼센트와 고정 결과 상태만 앱으로 반환하고 표시 라벨 원문은 반환·저장하지 않습니다. 모델별 특수 한도는 제외하며 페이지의 첫 퍼센트로 추정하거나 한도를 합치지 않습니다.
- **웹 확인의 공통 제한:** 로그인 입력·쿠키·토큰·웹 저장소·스크립트 소스·네트워크 응답 본문에 접근하지 않습니다. 전체 페이지 원문이나 원시 선택 텍스트를 앱 저장소·로그로 내보내지 않습니다. 지원하는 라벨·숫자·구조를 확인할 수 없으면 읽기를 중단하며 수치를 만들지 않습니다.
- **로컬 보관:** 서비스 구분·수동 확인 퍼센트·사용함/남음 의미·한도·확인 시각만 App Group 저장소에 보관해 앱과 같은 기기의 위젯이 공유합니다. 1.0(16) TestFlight의 Claude는 현재 세션·주간 숫자를 한도별로 따로 보관하며 주간을 대표로, 현재 세션을 별도로 표시합니다. Claude의 한 번 읽기는 세션·주간 모두 검증된 결과만 갱신하며 부분 결과로 어느 한도의 이전 값·확인 시각도 갱신하지 않습니다. 계정 ID·이메일·사용자 이름·원시 선택 텍스트·쿠키·토큰·서버 응답을 보관하지 않습니다. 사용함 값은 잔여율로 변환해 표시하며, 모델별 한도와 공급자별 수치를 합치지 않습니다.
- **수동 갱신:** 위젯은 마지막 저장 숫자를 표시하며 웹 로그인이나 새 사용량 요청을 수행하지 않습니다. Codex 새로고침도 이 숫자나 확인 시각을 갱신하지 않습니다. 수동 확인·한도·시각을 표시하고 1시간이 지나면 지난 확인으로 구분합니다. 수동 웹 경로의 자동 갱신은 없습니다. 위의 직접 연결 후보와는 별도입니다.
- **외부 처리:** 로그인·페이지 열기는 Grok·Claude 등 공식 서비스와 해당 로그인 제공자로 직접 전달됩니다. 제공자는 접속·인증·페이지 요청 정보를 처리할 수 있습니다. 개발자에게 웹 세션이나 실제 사용량을 보내지 않습니다. 사용자 로그인 성공이 해당 서비스의 타사 앱 허가 또는 App Store 승인까지 뜻하지는 않습니다.

앱 종료 후 웹 세션은 사라져도 마지막 숫자 캐시는 남습니다. **연결 해제·기록 삭제**를 선택하면 해당 서비스의 메모리 웹 세션과 모든 한도의 숫자 캐시를 정리합니다. 웹 계정을 바꾸려면 먼저 이 동작을 수행해 이전 숫자를 지운 뒤 공식 페이지에서 새 계정으로 로그인하세요. 이는 공급자 계정·구독 삭제나 모든 기기의 로그아웃을 수행하는 기능이 아닙니다.

## 예시 데이터

‘예시 데이터로 둘러보기’는 누구나 사용할 수 있는 오프라인 기능입니다. 실제 계정에 연결하지 않고 앱과 위젯에 ‘예시’로 표시한 샘플 값을 보여줍니다. 예시 새로고침은 로컬 표시 시각만 갱신하며 실제 사용량을 조회하지 않습니다. 예시 캐시는 실제 사용량 캐시와 분리됩니다. 직접 연결 후보도 예시가 켜져 있으면 인증정보·네트워크에 접근하지 않습니다. 예시 카드와 위젯에 실제 Grok·Claude 숫자를 혼합하지 않으며 두 서비스의 샘플 수치를 만들지 않습니다.

## macOS와 Windows

macOS와 Windows의 Codex 조회는 설치된 Codex CLI의 기존 로그인을 통해 사용량 메타데이터를 읽습니다. Codex 인증 파일·액세스 토큰을 직접 읽거나 개발자 서버로 보내지 않습니다.

macOS v0.3.0부터 제공한 추가 조회는 사용자가 본인의 공식 앱·CLI에 로그인하고 앱에서 연결에 동의한 범위에서 동작합니다. 배포 파일에는 개발자의 인증정보·계정 캐시가 포함되지 않습니다. Windows 공개 v0.3.1은 Codex 전용이며 0.4.0 공개 미리보기의 추가 연결은 아래에서 구분합니다. 이 macOS 공개본의 처리 방식은 위의 별도 iPhone 웹 확인 방식과 다릅니다.

- **기존 인증정보:** Claude는 기본 Claude Code Keychain 항목, Cursor 기반 Grok은 `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb` 안 `cursorAuth/accessToken` 한 항목만 사용합니다. 토큰은 앱 메모리에서만 사용하고 다른 DB 항목·계정·team·refresh token·기존 Grok Bot Safe Storage로 대체하지 않습니다. Claude는 앱 연결 동의 전 Keychain·HTTP에 접근하지 않습니다.
- **사용 목적과 네트워크:** Claude는 `https://api.anthropic.com/api/oauth/usage`, Cursor 기반 Grok은 `https://api2.cursor.sh/aiserver.v1.DashboardService/GetSandUsageStatus`에 직접 사용량을 요청합니다. 제공자는 IP 주소와 인증 요청 등 필요한 정보를 처리할 수 있습니다. 개발자 서버를 경유하지 않습니다. 기존 인증정보 자체가 사용량 전용 권한인 것은 아니며 앱 코드가 요청 대상·방식·응답 필드를 제한합니다.
- **최초 확인과 갱신:** Grok은 사용자가 시작한 최초 조회를 본인의 Grok 웹 사용률·리셋 시각과 대조해 일치한 뒤 자동 갱신을 활성화합니다. 검증 전 자동 경로는 인증 저장소·네트워크에 접근하지 않습니다. 연결된 표시 서비스는 600초마다 독립 갱신합니다. 내부 사용량 인터페이스 지원은 계정·구독과 제공자 변경에 따라 달라질 수 있습니다.
- **표시와 조회 중지:** 세 서비스의 표시 기본값은 켜짐입니다. 표시를 끄면 메뉴 막대에서 숨기고 자동·수동·잠자기 복귀 조회를 중지합니다. 이전 성공 값은 앱 메모리에만 남습니다. 모두 끈 경우에도 **사용량** 메뉴로 다시 설정할 수 있습니다. 20분 경과 또는 재조회 실패 값은 이전 값으로 구분합니다.
- **보관 범위:** macOS 사용량·리셋·마지막 성공 시각은 메모리에만 유지합니다. 연결 동의·검증·OS 권한 거부·표시 여부의 비민감 설정만 별도로 기억합니다. 실제 계정 한도·사용률·리셋 날짜·제품별 사용 내역을 문서·릴리스 이력·보고서에 기록하지 않습니다. Claude의 모델별 특수 한도는 상세 표시하며 공통 잔여율에서 제외합니다.
- **처리 제한:** OS 확인창은 명시적인 Claude 연결 요청에서만 허용하며 백그라운드 갱신은 확인창을 띄우지 않습니다. 조회기는 로그인·토큰 갱신·인증정보 저장·수정·마이그레이션을 수행하지 않습니다. 쿠키·대화 원문·세션 기록·다른 DB 항목을 읽지 않고 비밀값·원시 계정 응답·원시 오류를 로그나 새 파일에 남기지 않습니다. 만료되면 해당 공식 앱·CLI에서 사용자가 로그인해야 합니다.

## Windows 0.4.0 공개 미리보기의 추가 연결

Windows 0.4.0 공개 미리보기는 Codex·Claude·조건부 Grok 연결을 추가합니다. 기존 v0.3.1 ZIP은 Codex 전용입니다. 고정 소스·공개 파일·CI와 실계정 검증의 구분은 [배포 기록](releases/2026-10-20-windows-v0.4.0.md)을 따릅니다.

- **서비스별 동의:** Claude·Grok은 앱에서 명시적으로 사용량 조회에 동의하기 전 인증 저장소와 사용량 HTTP에 접근하지 않습니다. 공식 CLI·Cursor 로그인은 사용자가 설정에서 시작하고 직접 완료합니다. 공식 소프트웨어가 본인 인증정보를 관리하며 CodexTime은 로그인 출력을 수집하지 않습니다.
- **Claude:** 현재 사용자의 기본 `~/.claude/.credentials.json`을 제한된 크기로 읽어 `claudeAiOauth.accessToken`과 만료·필요 권한을 검증합니다. 다른 프로필·Claude Desktop·refresh token으로 대체하지 않습니다. 인증 파일을 갱신하거나 새 파일로 복사하지 않습니다.
- **Grok:** `%APPDATA%\Cursor\User\globalStorage\state.vscdb`를 읽기 전용 SQLite로 열어 `cursorAuth/accessToken` 한 항목만 조회합니다. 기존 DB·WAL·SHM과 고정 런타임을 검증하며 지원하지 않는 저장소, 누락된 sidecar, reparse point·네트워크 경로는 중단합니다. 다른 키·team·쿠키를 탐색하거나 DB·인증정보를 복사·수정하지 않습니다.
- **네트워크와 확인:** 토큰은 메모리에서 고정 Claude usage GET 또는 Cursor `GetSandUsageStatus` POST의 인증에만 사용합니다. 제공자는 IP·인증 요청 정보를 처리할 수 있습니다. Grok은 명시적인 최초 조회 결과를 본인 웹 사용률·리셋과 대조한 뒤 자동 갱신합니다. 내부 인터페이스 지원은 계정·구독에 따라 다릅니다.
- **보관·삭제:** 사용량·리셋·마지막 성공 시각·토큰은 앱 메모리에만 둡니다. 서비스 표시·연결 동의·Grok 대조·화면 설정 같은 비민감 값만 로컬 설정에 남습니다. 숨김은 조회를 중지하고 연결 해제는 앱의 허용·캐시만 지웁니다. 공식 CLI·Cursor 인증정보와 외부 계정·구독은 삭제하지 않습니다.
- **제한:** 쿠키·대화 원문·세션 기록·원시 HTTP 응답을 로그나 새 파일에 내보내지 않습니다. 앱은 토큰 갱신·모델 호출·개발자 서버 전송을 하지 않습니다. 실패 시 이전 성공 값을 이전 값으로 구분하며 수치를 만들지 않습니다.

## 중단된 iCloud 후보

공개 Mac v0.3.1과 다른 실험 브랜치에서 macOS 0.3.1(2026101907) 번호를 재사용하고 iPhone 1.0(12)을 사용한 비공개 iCloud 전달 후보는 서명·프로필 문제로 배포 전에 중단했습니다. 이 후보의 계약·실패 이력은 [보존 문서](releases/2026-10-19-private-icloud-sync.md)에 남기며, 현재 아이폰 단독 후보에도 iCloud 코드·권한·사용량 전송을 포함하지 않습니다. 당시 개인정보 커밋의 iCloud 설명을 현재 후보에 적용하지 않습니다.

## 보관과 삭제

macOS의 Claude·Grok **연결 해제**는 진행 중 조회를 정리하고 해당 앱 연결 플래그·메모리 캐시를 지웁니다. Claude Code Keychain·Cursor 원본 토큰을 삭제하거나 공식 앱을 로그아웃하지 않습니다. 계정을 바꾸려면 연결을 해제하고 공식 앱·CLI에서 로그인한 뒤 다시 연결하며, Grok은 웹 대조도 다시 완료합니다.

iPhone의 Codex ‘연결 해제’는 이 앱의 기기 내 Codex 토큰과 사용량 캐시를 삭제합니다. 수동 웹 경로의 ‘연결 해제·기록 삭제’는 각 서비스의 메모리 웹 세션과 모든 한도의 수동 숫자 캐시를 지웁니다. 1.0(17) 직접 연결 후보의 서비스 연결 해제는 해당 앱 전용 토큰과 직접 조회 캐시도 지우도록 설계했습니다. 앱 종료만으로 웹 숫자 캐시까지 삭제되지는 않습니다. ‘예시 끝내기’는 예시 캐시만 지웁니다. ChatGPT 계정·구독의 삭제나 해지는 수행하지 않으며 OpenAI 서비스에서 별도로 관리해야 합니다. 기기에 저장된 정보를 지우려면 앱 삭제 전에 연결 해제를 사용하세요.
