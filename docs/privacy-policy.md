# CodexTime 개인정보 처리방침

갱신일: 2026-10-19

CodexTime은 지원하는 서비스의 본인 사용량을 확인하는 비공식 오픈소스 유틸리티입니다. 개발자는 사용자 계정을 운영하지 않으며 광고·추적·분석 SDK나 별도 수집 서버를 사용하지 않습니다. 사용자가 선택한 iCloud 동기화는 Apple의 CloudKit을 사용합니다.

이 문서의 새 동기화 계약은 macOS 0.3.1(2026101907)·iPhone 1.0(12) 후보를 대상으로 합니다. 코드 구현·서명·설치·실제 동기화·TestFlight 처리 완료는 각각 별도 검증 항목이며, 이 문서 자체가 배포 완료를 뜻하지 않습니다. 실제 배포 상태는 [루트 README](../README.md)와 릴리스 기록을 확인하세요. macOS 0.3.0과 iPhone 1.0(11)의 이전 동작은 [통신 규약](protocol.md)에 구분해 보존합니다.

## iPhone에서 직접 처리하는 Codex 정보

- **인증 정보:** OpenAI의 외부 기기 인증 페이지에서 사용자가 연결을 승인합니다. 앱은 비밀번호를 직접 입력받지 않습니다. 발급된 ID·액세스·갱신 토큰은 iCloud 동기화되지 않는 기기 전용 Keychain에 저장하며, 같은 서명 그룹의 앱과 위젯만 공유합니다. ID 토큰에는 OpenAI가 발급한 계정 관련 정보가 포함될 수 있습니다.
- **계정 식별자:** 사용량 요청을 인증하기 위해 토큰에서 계정 식별자를 읽어 OpenAI에 전송합니다.
- **사용량:** 기본 한도의 남은 비율, 리셋 시각, 마지막 갱신 시각과 제공되는 경우 누적 토큰을 앱과 위젯의 공유 저장소에 캐시합니다. 프로필 응답에서 이름·사진·사용자명은 저장하지 않고 누적 토큰 숫자만 읽습니다. 대화·프롬프트 내용은 요청하지 않습니다.
- **네트워크:** 인증과 사용량 요청은 OpenAI로 직접 전달됩니다. OpenAI는 IP 주소와 요청 등 서비스 제공에 필요한 정보를 처리할 수 있습니다. 외부 지원·소스 페이지를 열면 GitHub의 접속 정보 처리 정책이 적용됩니다.

Codex의 직접 조회는 iCloud 동기화와 별개입니다. 개발자에게 사용량이나 인증 토큰을 보내지 않습니다. ‘수집 서버가 없다’는 말은 Apple·OpenAI 등 외부 제공자가 네트워크 정보를 전혀 처리하지 않는다는 뜻이 아닙니다.

## 선택한 iCloud 동기화

동기화는 Mac과 iPhone에서 **기본 꺼짐**이며 사용자가 각각 켜야 합니다. 두 기기가 같은 본인 Apple 계정의 iCloud를 사용해야 합니다. Mac은 기존에 연결·검증한 Grok 사용량의 최소 결과만 `iCloud.com.sundaynighttt.codextime` 컨테이너의 **본인 비공개 CloudKit 데이터베이스**에 저장하고 iPhone은 이를 읽습니다. 다른 사용자의 데이터베이스나 개발자 서버를 경유하지 않습니다.

- **전송 허용 필드:** 서비스 구분, 정수 잔여율, 리셋 시각, 공급자 조회 시각, 고정 상태 값만 사용합니다. Claude는 공급자 제한 때문에 수치 없이 차단 상태만 허용합니다.
- **전송하지 않는 정보:** 비밀번호, API 키, OAuth·갱신 토큰, 쿠키, 인증 파일, 계정 ID·이메일·구독 이름, 기기 이름, 누적 토큰, 제품별 사용 내역, 대화·프롬프트, 원시 공급자 응답·오류는 동기화하지 않습니다. 자격증명은 원래 기기의 승인된 조회 경로에만 남습니다.
- **Apple 처리:** 선택한 필드는 기기에서 Apple CloudKit으로 전송·보관됩니다. Apple은 iCloud 계정·접속 등 서비스 운영에 필요한 정보를 처리할 수 있습니다. 본인 비공개 데이터베이스 사용이 Apple에도 데이터가 전혀 전달되지 않는다는 뜻은 아닙니다.
- **로컬 캐시와 계정 격리:** Mac과 iPhone은 iCloud 계정 범위가 확인된 동기화 값만 로컬에 캐시하며, iPhone 앱과 위젯은 같은 기기의 공유 저장소를 사용합니다. iCloud 계정 변경·로그아웃 시 앱의 동기화 선택과 해당 캐시를 지우며, 새 계정에서는 다시 켜야 합니다. 이 범위 확인은 인증 토큰이나 계정 식별자를 동기화 필드로 보내는 방식이 아닙니다.
- **최신성:** 최신 Grok 값을 만들려면 Mac이 깨어 있고 앱이 실행 중이며 해당 서비스 연결·표시·네트워크가 유지돼야 합니다. 서비스 조회는 10분 간격이며 CloudKit·WidgetKit의 실제 전달·실행 시점은 보장하지 않습니다. Mac이 꺼져 있으면 마지막 공급자 조회 시각을 유지하고 20분 경과 값은 ‘오래된 정보’로 표시합니다. 동기화 실패도 연결 오류와 마지막 조회 시각을 구분합니다.

예시 모드는 실제 iCloud 값을 섞거나 예시 수치를 업로드하지 않습니다. iPhone이 Grok·Claude 웹 로그인이나 세션 수집을 수행하지 않습니다.

## macOS와 Windows

macOS와 Windows의 Codex 조회는 설치된 Codex CLI의 기존 로그인을 통해 사용량 메타데이터를 읽습니다. 앱이 Codex 인증 파일·액세스 토큰을 직접 읽거나 개발자 서버로 보내지 않습니다. Windows는 현재 Codex 전용입니다.

macOS의 Cursor 기반 Grok 조회는 `~/Library/Application Support/Cursor/User/globalStorage/state.vscdb` 안 `cursorAuth/accessToken` 한 항목만 읽어 고정 사용량 RPC에 사용합니다. 토큰은 앱 메모리에서만 사용하며 다른 DB 항목·계정·team·refresh token·기존 Grok Bot Safe Storage로 대체하지 않습니다. 쿠키·대화 원문·세션 기록은 읽지 않습니다. 요청은 `https://api2.cursor.sh/aiserver.v1.DashboardService/GetSandUsageStatus`에 직접 전달되며, 제공자는 IP 주소와 인증 요청 등 필요한 정보를 처리할 수 있습니다. 원본 토큰이 사용량 전용 권한인 것은 아니며 앱 코드가 요청 대상·방식·응답 필드를 제한합니다.

Grok은 사용자가 시작한 최초 조회를 같은 계정·구독 기간의 Grok 웹 사용률·리셋 시각과 대조한 뒤 자동 갱신합니다. 검증 전 자동 경로는 인증 저장소·네트워크에 접근하지 않습니다. 연결된 표시 서비스는 600초마다 독립 갱신합니다. 표시를 끄면 해당 서비스의 자동·수동·잠자기 복귀 조회를 중지합니다. 이미 수신한 iCloud 값이 즉시 원격 삭제되는 것은 아닙니다.

**Claude의 기존 자동 조회는 새 후보에서 차단합니다.** Anthropic의 [Authentication and credential use](https://code.claude.com/docs/en/legal-and-compliance#authentication-and-credential-use)는 “developers may not collect, store, or intermediate Claude.ai credentials or session tokens”라고 규정합니다. 새 경로는 Claude Code Keychain 읽기·OAuth 사용량 요청·수치 동기화를 수행하지 않으며 공식 [Claude 사용량 페이지](https://claude.ai/settings/usage)를 안내합니다. macOS 0.3.0의 과거 Keychain 기반 동작과 실제 조회 이력은 현재 허용 방식의 근거가 아닙니다. 이전 버전을 사용하는 경우 Claude 연결을 해제하세요.

배포 파일에는 개발자의 인증정보·계정 캐시가 포함되지 않습니다. 실제 계정 수치·리셋 날짜·제품별 사용 내역·비밀값·원시 오류를 문서·릴리스 기록·진단 로그에 남기지 않습니다. macOS의 일반 조회 캐시는 메모리에 유지합니다. 동기화에 동의하면 위 허용 필드를 계정 범위에 묶어 로컬 캐시와 Apple 비공개 저장소에도 저장합니다.

## 예시 데이터

‘예시 데이터로 둘러보기’는 누구나 사용할 수 있는 오프라인 기능입니다. 실제 계정에 연결하지 않고 앱과 위젯에 ‘예시’로 표시한 샘플 Codex 값을 보여줍니다. 예시 새로고침은 로컬 표시 시각만 갱신하며 실제 사용량을 조회하지 않습니다. 예시 캐시는 실제 사용량·iCloud 캐시와 분리됩니다. Grok·Claude의 수치를 만들거나 Codex 값을 복제하지 않습니다.

## 보관과 삭제

- **iPhone 수신 해제:** **이 iPhone에서 동기화 해제**는 이 기기의 새 수신·표시와 로컬 동기화 캐시만 정리합니다. 다른 기기의 설정이나 iCloud 레코드는 삭제하지 않습니다.
- **Mac 동기화 끄기와 삭제:** Mac에서 동기화 체크를 끄거나 **끄고 iCloud 값 삭제**를 선택하면 이 Mac의 전송·로컬 캐시를 중지·정리한 뒤 본인 비공개 저장소의 사용량 레코드 삭제도 요청합니다.
- **iPhone의 iCloud 데이터 삭제:** **iCloud 동기화 데이터 삭제**는 수신 해제와 별도로 본인 비공개 저장소의 사용량 레코드 삭제를 요청합니다.
- **삭제 확인과 재시도:** Mac·iPhone 모두 Apple의 삭제 성공 응답을 받은 뒤에만 삭제 완료로 처리합니다. 네트워크가 없거나 삭제 응답을 받지 못하면 ‘삭제 대기’로 표시하며 삭제 완료라고 주장하지 않습니다. 다시 연결한 뒤 재시도해야 합니다. 다른 Mac의 동기화가 켜져 있으면 이후 다시 업로드할 수 있으므로 전체 중단에는 각 Mac에서도 동기화를 끄세요.
- **iCloud 로그아웃·계정 변경:** 해당 계정의 로컬 캐시·동기화 선택을 지웁니다. 로그아웃은 이전 계정의 클라우드 레코드를 삭제하는 동작이 아닙니다. 필요하면 로그아웃 전에 삭제를 완료하세요.
- **macOS Grok 연결 해제:** 진행 중 조회와 앱 연결·검증 상태·메모리 캐시를 정리합니다. Cursor 원본 토큰을 삭제하거나 공식 앱을 로그아웃하지 않습니다. 계정 변경 전 연결을 해제하고 공식 앱에서 새 계정에 로그인한 뒤 웹 대조를 다시 완료하세요.
- **iPhone Codex 연결 해제:** 이 앱의 기기 내 Codex 토큰과 사용량 캐시를 지웁니다. iCloud 동기화는 별도 설정이므로 전체 중단·삭제를 원하면 위 동작도 수행하세요. ‘예시 끝내기’는 예시 캐시만 지웁니다. ChatGPT 계정·구독의 삭제나 해지는 수행하지 않습니다.
