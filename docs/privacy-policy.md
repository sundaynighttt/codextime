# CodexTime 개인정보 처리방침

갱신일: 2026-09-04

CodexTime은 사용자가 자신의 Codex 사용량을 확인하는 비공식 오픈소스 유틸리티입니다. 개발자는 사용자 계정을 운영하지 않으며 광고·추적·분석 SDK나 별도 데이터 수집 서버를 사용하지 않습니다.

## iPhone에서 처리하는 정보

- **인증 정보:** OpenAI의 외부 기기 인증 페이지에서 사용자가 연결을 승인합니다. 앱은 비밀번호를 직접 입력받지 않습니다. 발급된 ID·액세스·갱신 토큰은 iCloud 동기화되지 않는 기기 전용 Keychain에 저장하며, 같은 서명 그룹의 앱과 위젯만 공유합니다. ID 토큰에는 OpenAI가 발급한 계정 관련 정보가 포함될 수 있습니다.
- **계정 식별자:** 사용량 요청을 인증하기 위해 토큰에서 계정 식별자를 읽어 OpenAI에 전송합니다.
- **사용량:** 기본 한도의 남은 비율, 리셋 시각, 마지막 갱신 시각과 제공되는 경우 누적 토큰을 앱과 위젯의 공유 저장소에 캐시합니다. 프로필 응답에서 이름·사진·사용자명은 저장하지 않고 누적 토큰 숫자만 읽습니다. 대화·프롬프트 내용은 요청하지 않습니다.
- **네트워크:** 인증과 사용량 요청은 OpenAI로 직접 전달됩니다. OpenAI는 IP 주소와 요청 등 서비스 제공에 필요한 정보를 처리할 수 있습니다. 외부 지원·소스 페이지를 열면 GitHub의 접속 정보 처리 정책이 적용됩니다.

개발자에게 사용량이나 인증 토큰을 보내지 않습니다. ‘수집 서버가 없다’는 말은 외부 인증·호스팅 제공자가 네트워크 정보를 전혀 처리하지 않는다는 뜻이 아닙니다.

## 예시 데이터

‘예시 데이터로 둘러보기’는 누구나 사용할 수 있는 오프라인 기능입니다. 실제 계정에 연결하지 않고 앱과 위젯에 ‘예시’로 표시한 샘플 값을 보여줍니다. 예시 새로고침은 로컬 표시 시각만 갱신하며 실제 사용량을 조회하지 않습니다. 예시 캐시는 실제 사용량 캐시와 분리됩니다.

## macOS와 Windows

데스크톱 앱은 설치된 Codex CLI의 기존 로그인을 통해 사용량 메타데이터를 읽습니다. 인증 파일·브라우저 쿠키·토큰을 직접 수집하거나 개발자 서버로 보내지 않습니다.

## 보관과 삭제

iPhone의 ‘연결 해제’는 이 앱의 기기 내 토큰과 사용량 캐시를 삭제합니다. ‘예시 끝내기’는 예시 캐시만 지웁니다. ChatGPT 계정·구독의 삭제나 해지는 수행하지 않으며 OpenAI 서비스에서 별도로 관리해야 합니다. 기기에 저장된 정보를 지우려면 앱 삭제 전에 연결 해제를 사용하세요.
