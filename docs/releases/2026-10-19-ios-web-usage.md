## 동작과 저장 범위

Codex는 기존 iPhone OpenAI 기기 로그인·직접 사용량 조회를 유지한다. Grok·Claude는 각 공식 웹을 앱의 독립적인 **nonPersistent WKWebView**에서 열어 사용자가 직접 로그인하고 공식 사용량 화면을 확인한다. Mac·Cursor·iCloud·개발자 서버·API 키가 필요하지 않다. 비밀번호·2FA·SSO는 공식 웹에서 사용자가 처리하며 앱이 대신 제출하지 않는다.

사용자는 공식 사용량 숫자가 보임을 확인한 뒤 **사용함/남음**과 읽을 한도를 선택하고 **숫자 위치 지정해서 읽기**를 눌러 15초 안에 해당 %를 한 번 탭한다. 이 한 번의 직접 탭은 이동·버튼 실행 대신 숫자 읽기에 사용되며, 미입력 시 취소한다. 선택한 의미·한도는 읽기 시작 때 고정하고 웹 문구로 자동 추정하지 않는다. Grok은 주간 한도, Claude는 현재 세션/주간 중 선택한 한도다. 화면 구조·공식 주소·표시된 숫자를 검증하지 못하면 읽기를 중단하고 수치를 만들지 않는다. 사용률을 읽으면 잔여율로 변환하고, 다른 공급자/한도의 값과 합치지 않는다. 페이지 전체 덤프·쿠키/토큰 열람·내부 quota API 요청을 추가하지 않는다.

웹 로그인 세션은 앱 실행 중 WebKit 메모리에만 유지된다. 창을 닫고 다시 열어도 같은 앱 실행 중에는 유지될 수 있으나 앱 종료·연결 해제 후에는 재로그인이 필요하다. 앱은 쿠키·토큰을 Keychain이나 파일에 복사하지 않는다. 연결 유지·자동 갱신을 약속하지 않는다.

앱과 위젯에 보관하는 것은 서비스 구분·수동 확인 퍼센트·사용함/남음 의미·선택한 한도·확인 시각뿐이다. 위젯은 마지막 숫자를 읽고 웹에 로그인하거나 새 사용량을 가져오지 않는다. 카드에는 수동 확인·한도·시각을 표시하며 1시간 지난 값은 지난 확인으로 구분한다. 오래됐다는 이유만으로 저장 숫자를 지우지는 않는다. 앱 종료 후에도 이 숫자 캐시는 남고 웹 세션만 사라진다. **연결 해제·기록 삭제**는 해당 서비스의 메모리 세션과 숫자 캐시를 정리한다. Codex 새로고침은 웹 숫자의 갱신 시각을 바꾸지 않는다. 예시 모드에는 실제 웹 숫자를 섞지 않는다.
