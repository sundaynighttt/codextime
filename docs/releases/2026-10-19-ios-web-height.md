## 문제와 변경

사용자는 빌드 13의 공통 웹 연결 화면에서 상단의 긴 안내와 하단 숫자 설정이 공간을 차지해 실제 로그인 화면이 잘 보이지 않는다고 보고했다. Grok·Claude가 공통으로 쓰는 `ProviderWebUsageView`의 배치를 수정했다.

- 큰 고정 안내를 제거하고 공급자·현재 호스트를 네이티브 상단 바에 표시한다. 전체 안내는 **더 보기 → 도움말**에서 필요할 때 연다.
- 기본 하단은 **사용량 열기**와 필요한 조작만 한 줄로 둔다. 기본 한 줄 높이는 최소 44pt에 상하 합계 8pt 여백이다. 사용량 화면에서는 **읽기 설정**과 **숫자 읽기**를 제공한다.
- 숫자 표시 확인·사용함/남음·현재 세션/주간 선택은 별도의 **읽기 설정** 시트에 모았다. 설정 후 완료하면 웹 화면으로 돌아와 **숫자 읽기**를 누른다.
- 소프트웨어 키보드가 열리면 하단 조작을 숨기고 상단 **키보드 닫기**를 제공한다. 웹 로그인 폼의 자체 스크롤을 유지한다.

같은 WKWebView 메모리 세션을 유지한다. 변경 소스는 원격 후보 브랜치에 push가 확인된 `da7d7620f9b7891cc0f837f3f32a94923f81817e`이며 웹뷰 표시 파일과 빌드 번호 설정 2개, 총 3개 파일만 변경했다. 인증·사용량 모델·Coordinator·파서·캐시·권한·개인정보 처리 경로는 바꾸지 않았다. 정책 고정 링크 `694397676e700a164cb9d931b449a230267fe865`를 유지한다. 빌드 13의 [기능·배포 기록](2026-10-19-ios-web-usage.md)은 별도로 보존한다.
