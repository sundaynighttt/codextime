# Windows 0.4.0 — 세 서비스 연결 후보

**현재 단계: source candidate / 검증 중.** 새 Windows 공개 ZIP·태그·릴리스를 완료한 것으로 표시하지 않습니다. 현재 공개 Windows v0.3.1은 Codex 전용이며 macOS v0.3.1·iPhone TestFlight 1.0(16)의 런타임과 이미지는 유지합니다.

## 변경 범위

- 작업표시줄 표시·미니 위젯에 Codex·Grok·Claude 세 로고와 독립 잔여율을 기본 표시합니다. 공통 한도의 최소 잔여율을 내림하고 Claude 모델별 한도와 제품별 사용 비중은 합산하지 않습니다.
- 계정 설정, 공식 Codex·Claude CLI 로그인 및 Cursor 로그인 안내, 서비스별 조회 동의·숨김·연결 해제를 추가합니다. 숨김은 조회를 취소·중지하며 모두 숨기면 사용량 진입점을 유지합니다.
- 기본 10분 갱신, 1분 카운트다운, 선택적 리셋 표시(기본 꺼짐), 조회 실패·20분 경과 이전 값, 공급자별 취소·오류 격리를 적용합니다.
- Claude는 기본 Windows Claude Code OAuth access token을 메모리에서 고정 Anthropic usage GET에 사용합니다. Grok은 기본 Cursor DB 단일 키의 읽기 전용 조회와 고정 usage POST를 사용하며 본인 웹 사용률·리셋 대조 뒤 자동 갱신합니다.
- Cursor DB·WAL·SHM의 기존 파일·경로와 SQLite 3.53.4를 검증합니다. 지원하지 않는 저장소는 중단하며 쿠키·다른 프로필·refresh token·DB 복사·수정·인증정보 저장 경로를 추가하지 않습니다.

## 검증과 배포 경계

네이티브 Windows 빌드·단위/가짜 전송·합성 저장소 시험·패키지·미리보기 결과는 실행 근거를 확인한 뒤 이 문서와 원장에 기록합니다. 현재 이 문서는 해당 검사의 통과나 공개 배포를 주장하지 않습니다.

실물 Windows에서 본인 Codex·Claude·Grok 계정의 로그인·숫자·리셋 대조, 절전 복귀·Explorer 재시작·앱 업데이트는 아직 별도 검증 항목입니다. 에이전트는 실제 인증 파일·토큰·DB·쿠키·세션 원문을 읽거나 실제 사용량 요청을 실행하지 않습니다. 합성 시험과 화면 예시는 실제 계정 성공의 증거가 아닙니다.

예정 패키지 버전은 **0.4.0**이며 릴리스 식별자는 공개를 확인한 뒤 확정합니다. Windows 실행 파일·설치 스크립트의 코드 서명은 별도 미완료입니다. 공개 시 ZIP 내용·SHA256·의존성 라이선스 고지를 검증하고 다운로드 표의 기존 v0.3.1과 구분해야 합니다.
