# Windows 0.4.0 — 세 서비스 공개 미리보기

**현재 단계: released / public prerelease.** [windows-v0.4.0](https://github.com/sundaynighttt/codextime/releases/tag/windows-v0.4.0)을 **2026-10-20 08:57:32 KST**에 공개했습니다. 일반 공개 미리보기이며, 실물 Windows에서 본인 계정·절전 복귀·Explorer 재시작을 완료한 것으로 확대하지 않습니다. 기존 Windows v0.3.1은 Codex 전용이고 macOS v0.3.1·iPhone TestFlight 1.0(16)은 별도 배포본입니다.

## 다운로드와 고정 소스

- [CodexTime-Windows-0.4.0.zip](https://github.com/sundaynighttt/codextime/releases/download/windows-v0.4.0/CodexTime-Windows-0.4.0.zip) — **73,039,567 bytes**
- [SHA256SUMS-Windows.txt](https://github.com/sundaynighttt/codextime/releases/download/windows-v0.4.0/SHA256SUMS-Windows.txt)
- ZIP SHA-256: `f080c5396020a6a49f36fb62500f5fb0b9673b2b32d7e4c60a1cb667cba1ea25`
- 고정 소스: [`5e026a0027e5fa6c52b602f6986d294245564625`](https://github.com/sundaynighttt/codextime/commit/5e026a0027e5fa6c52b602f6986d294245564625)

공개 ZIP은 위 소스에서 생성한 동일 산출물을 유지합니다. 이후 README·설치·검증 문서 보강을 새 실행 파일 배포로 해석하지 않습니다. Windows 실행 파일과 설치 스크립트는 코드 서명되지 않았습니다.

## 변경 범위

- 작업표시줄 표시·미니 위젯에 Codex·Grok·Claude 세 로고와 독립 잔여율을 기본 표시합니다. 공통 한도의 최소 잔여율을 내림하고 Claude 모델별 한도와 제품별 사용 비중은 합산하지 않습니다.
- 계정 설정, 공식 Codex·Claude CLI 로그인 및 Cursor 로그인 안내, 서비스별 조회 동의·숨김·연결 해제를 추가합니다. 숨김은 조회를 취소·중지하며 모두 숨기면 사용량 진입점을 유지합니다.
- 기본 10분 갱신, 1분 카운트다운, 선택적 리셋 표시(기본 꺼짐), 조회 실패·20분 경과 이전 값, 공급자별 취소·오류 격리를 적용합니다.
- Claude는 기본 Windows Claude Code OAuth access token을 메모리에서 고정 Anthropic usage GET에 사용합니다. Grok은 기본 Cursor DB 단일 키의 읽기 전용 조회와 고정 usage POST를 사용하며 본인 웹 사용률·리셋 대조 뒤 자동 갱신합니다.
- Cursor DB·WAL·SHM의 기존 파일·경로와 SQLite 3.53.4를 검증합니다. 지원하지 않는 저장소는 중단하며 쿠키·다른 프로필·refresh token·DB 복사·수정·인증정보 저장 경로를 추가하지 않습니다.

## 검증 근거와 한계

[CI 39344190966](https://github.com/sundaynighttt/codextime/actions/runs/39344190966)의 **Windows WPF·macOS Swift·iPhone widget 세 작업 모두 성공**을 확인했습니다.

- Windows Release 빌드: **경고 0·오류 0**.
- 파서·공급자 상태·가짜 HTTP·네이티브 합성 저장소·UI 검사를 통과했습니다. 고정 SQLite·기존 WAL/SHM·단일 키·읽기 전용 경계를 합성 파일로 검증했습니다.
- publish한 실행 파일을 대상으로 동일 검사를 통과했고 작업표시줄·미니 위젯·설정·상세 **PNG 4종**을 생성했습니다. 예시 수치만 사용하며 실제 계정이나 인증정보는 포함하지 않습니다.
- npm `.cmd`·`.bat` 로그인 래퍼의 고정 인수 전달 합성 시험을 고정 소스 `5e026a0`에서 통과했습니다. 네이티브 `.exe` 설치도 연결 대상으로 지원합니다.
- 로그인 없는 공개 ZIP 다운로드에 성공했고, 다운로드한 파일의 SHA-256이 CI 원본 및 GitHub 자산 체크섬과 일치했습니다. x64 PE·필수 설치 파일·라이선스 고지도 확인했습니다.

첫 [CI 39343611771](https://github.com/sundaynighttt/codextime/actions/runs/39343611771)는 합성 WAL 해시 검사 도우미의 파일 공유 모드 누락으로 실패했고 [`f44d4fa`](https://github.com/sundaynighttt/codextime/commit/f44d4fa)에서 시험 도우미를 보완했으며 실제 앱 저장소 조회 취약점으로 확인된 실패는 아닙니다.

실물 Windows에서 본인 Codex·Claude·Grok 계정의 로그인·숫자·리셋 대조, 절전 복귀·Explorer 재시작·앱 업데이트는 아직 별도 미확인입니다. 실제 인증 파일·토큰·DB·쿠키·세션 원문을 시험에 사용하거나 실제 사용량 요청을 실행하지 않았습니다. 합성 시험·공개 다운로드·화면 예시를 실제 계정 성공으로 간주하지 않습니다.
