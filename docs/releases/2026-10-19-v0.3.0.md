# v0.3.0 — macOS 세 서비스와 본인 계정 설정

**0.3.0 (2026101906)을 2026-10-19 12:44 KST에 정식 공개했다.** 로컬 universal 설치·설정 화면 검증과 GitHub 서명·공증 빌드, 실제 DMG 다운로드 검증을 완료했다. [공개 릴리스](https://github.com/sundaynighttt/codextime/releases/tag/v0.3.0)

- Codex·Grok·Claude 세 로고를 기본 표시하고 메뉴와 설정 창에서 각각 끌 수 있다. 끄면 해당 서비스의 자동·수동 조회를 중지하고 진행 중 요청을 정리한다. 전부 끄면 복구용 '사용량' 표시를 남긴다.
- 첫 실행과 앱 재열기에서 계정 연결·표시 설정을 제공한다. 다른 사용자는 자신의 공식 Codex CLI·Claude Code·Cursor 로그인만 사용하며 개발자 인증정보는 포함하지 않는다.
- Claude는 명시적 연결 전 Keychain 접근을 차단한다. Grok는 Cursor 단일 항목 사용 동의와 일회성 조회 후 본인이 웹 사용량·reset 일치를 확인해야 10분 갱신을 시작한다. 연결 해제는 앱의 확인 상태와 캐시만 지우며 원본 인증정보를 삭제하지 않는다.
- 99개 합성·회귀 테스트가 6.825초에 통과했다. 기본 표시, 개별/전체 숨김, 재표시, 요청 중 취소·재활성화, 연결 해제 경쟁, 새 사용자 동의 전 인증·네트워크 무접근을 포함한다. 기존 Codex read hang·자식 프로세스 정리와 독립 WAL 무변경 검증도 유지한다.
- 로컬 실행파일은 arm64+x86_64 universal이며 설치된 실제 설정 창에서 세 기본 선택, 전체 숨김의 복구 표시, 전체 재표시를 확인했다. Claude 앱 내 연결도 완료되어 세 공급자의 실제 성공 상태와 표시를 확인했다. 실제 계정 사용량·reset·계정 식별자는 문서에 저장하지 않았다.
- 로컬 미공증 후보 실행파일 SHA256: 241711b55e76b6299e579599fd0365ce48418894bdf446971899436ff7ad679d. 직전 설치본 전체는 ~/Applications/Codex Usage Monitor.backup-20261019-031232.app에 보존했다.
- universal 실행파일 생성 후 최신 lipo의 복수 아키텍처 검증 명령이 실패했다. 각 아키텍처를 별도로 검증하도록 수정한 뒤 앱 패키징을 완료했다. 검증 실패 중에는 기존 설치본을 변경하지 않았다.
- 첫 GitHub CI에서는 동시성 테스트 2개가 고정 대기 시간에 의존해 실패했다. 느린 응답과 취소 후 정리를 명시적 신호로 제어하도록 테스트만 수정했고, 로컬 전체 99개가 6.742초에 재통과했다. 제품 코드와 설치 후보는 바뀌지 않았다.
- 병합 후 CI에서는 가짜 WAL 작성용 시스템 Python의 최초 시작이 3초 제한을 넘겨 실패했다. 실제 DB나 production 읽기 제한과 무관한 fixture 준비 신호의 대기 한도를 15초로 조정했다. 고정 sleep을 추가하지 않으며 준비 바이트를 받으면 즉시 진행한다.
- 공개 워크플로는 Developer ID 설정 누락 시 실패하며 앱과 DMG 각각의 공증 Accepted·staple·Gatekeeper 검증을 요구한다. 검증 산출물은 먼저 draft Release에만 올리고 다운로드 검증 후 공개한다. Windows ZIP은 기존 Codex 전용이다.

설정 방법은 [macOS 설치·본인 계정 연결](../macos-setup.md), 인증·조회 경계는 [통신 규약](../protocol.md#macos-공급자별-상태)을 따른다.

다운로드한 초안 DMG SHA256은 886b29fa76b64095f9ebbda2a63e7d4a5bbb641ef10f0517ca2515ae794304aa이다. SHA256SUMS 일치, DMG·내부 앱의 공증 티켓과 Notarized Developer ID 허용, arm64·x86_64 각각의 최소 macOS 13.0을 확인했다. [릴리스 워크플로](https://github.com/sundaynighttt/codextime/actions/runs/39195054137)가 서명·공증·초안 업로드를 모두 완료했다.

정식 공개 뒤 GitHub 인증 없이 DMG를 다시 다운로드해 같은 SHA256임을 확인했다. 최신 main CI도 세 플랫폼 모두 통과했다. 정식 서명본을 로컬에 설치하고 원본과 실행파일 SHA256 12beb1466ab6a6d94323ceee9b5e801e1fdef38e99812189dbedf461da09a36c 일치 및 strict 서명 검증을 확인했다. 이전 후보 전체는 ~/Applications/Codex Usage Monitor.backup-20261019-033935.app에 보존했다. 서명이 바뀐 앱의 Claude Keychain 접근은 사용자가 해당 앱에서 다시 허용해야 할 수 있다.
