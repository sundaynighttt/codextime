# v0.3.1 — macOS 간편 설정과 로그인 복구

macOS **0.3.1 (2026101907)**은 앱 안에서 계정 연결과 로그인 복구를 진행하도록 개선한 버전입니다. [사용법](../macos-setup.md) · [변경 PR #16](https://github.com/sundaynighttt/codextime/pull/16)

## 변경 내용

- 서비스별 설치·로그인 상태와 연결 완료 수를 표시합니다. 정상 연결된 서비스에는 재설치·로그인 안내를 반복하지 않습니다.
- Codex·Claude의 **로그인하기**가 설치된 공식 CLI의 브라우저 로그인을 실행하고, 종료 후 실제 사용량을 다시 확인합니다. 로그인 취소와 10분 대기 제한을 제공합니다.
- Grok 로그인은 Cursor를 열고 간편 설정으로 돌아왔을 때 연결을 다시 확인합니다. 웹 사용률·리셋 대조가 끝나야 설정 완료로 판정합니다.
- Finder에서 실행할 때도 현재 ChatGPT/Codex 앱의 내장 CLI와 기본·nvm 설치를 찾습니다.
- 기존 연결과 동의를 유지하고, 설정 창에서 로그인 시 자동 실행을 선택할 수 있습니다. DMG에 **시작하기.html**을 포함합니다.

공식 앱·CLI가 없으면 공식 설치 안내를 엽니다. 로그인·macOS 권한 승인·Grok 웹 확인은 사용자 본인이 완료합니다. Windows는 기존 Codex 전용이며 간편 설정 변경은 macOS 기능입니다.

## 검증

- macOS 전체 **109개 테스트**와 Windows·iPhone CI가 통과했습니다. [기능 변경 CI](https://github.com/sundaynighttt/codextime/actions/runs/39202031108)
- 로그인 인수, 실패 후 재시도, 취소, SIGTERM에 응답하지 않는 프로세스의 시간 초과 정리, 동의 마이그레이션·철회, Grok 웹 확인 전 완료 방지를 검사했습니다.
- 가상 계정으로 로그인 필요 → 로그인 버튼 → 자동 사용량 확인 → 설정 완료 흐름을 실제 설정 창에서 확인했습니다.
- [검증용 서명 빌드](https://github.com/sundaynighttt/codextime/actions/runs/39202030823)의 universal DMG·내부 앱은 Developer ID 서명과 Apple 공증을 통과했습니다. M2 MacBook Air에 설치해 기존 세 서비스 연결 유지와 실제 조회, CODEX_CLI_PATH 없는 실행을 확인했습니다.
- 공개 태그의 최종 설치 파일은 릴리스 워크플로에서 다시 빌드·서명·공증합니다. 공개 후 다운로드와 체크섬 검증 근거를 추가합니다.

계정 식별자·토큰·실제 계정 응답은 이 문서에 기록하지 않습니다.
