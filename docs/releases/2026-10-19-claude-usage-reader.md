**현재 단계: external_processed / passed.** 빌드16은 XCTest 80개·최종 Release·archive 서명을 통과했고 **2026-10-19 23:40:44 KST 업로드·23:43:46 KST Apple 테스트 가능 알림**을 확인했다. Apple 처리 확인 최신은 **1.0(16)**이며 기존 테스터가 설치·업데이트할 수 있다. 사용자 iPhone의 새 숫자·위젯 대조는 아직 별도 확인이 필요하다.

## 사용자 확인과 수정 범위

사용자가 Claude 로그인 성공과 공식 사용량 패널 도달을 보고했고 부모가 제공 화면을 확인했다. 실제 퍼센트·계정 식별자·사진·인증 URL은 저장하지 않는다. 이전 Google/새창 제한과 링크 오류 이력은 [빌드15 기록](2026-10-19-claude-login-recovery.md)에 보존한다. 새 보고가 Google OAuth 지원 완료를 뜻하지는 않는다.

기존 Mac Chrome의 공식 사용량 페이지가 `/new#settings/usage`로 열리는 것을 확인했다. 기존 `/settings/usage` 및 fragment 없음 조건과 달라 실제 패널에서도 읽기 버튼이 숨거나 하단이 로그인 안내로 남을 수 있었고, 의미·한도를 고른 뒤 숫자를 다시 탭해야 했다. 빌드16은 Claude 공식 HTTPS 호스트에서 **사용량 읽기**를 한 번 눌러 현재 세션·전체 모델 주간을 구분한다. Grok의 기존 사용자 확인·의미·한도 선택과 위치 탭 읽기는 유지한다.

## 처리·저장 계약

- 보이는 사용량 패널의 정해진 짧은 한국어·영어 라벨과 가까운 퍼센트만 제한된 DOM 검사로 해석한다. 첫 퍼센트로 추정하지 않고 모델별 특수 한도를 제외한다.
- 앱으로 반환하는 정보는 검증된 한도별 숫자와 고정 결과 상태뿐이다. 로그인 입력·쿠키·토큰·웹 저장소·전체 페이지 원문·스크립트 소스·네트워크 응답에 접근하거나 이를 로그·파일로 내보내지 않는다.
- `provider`, `percent`, `valueKind`, `metric`, `updatedAt`만 같은 기기의 App Group에 한도별 보관한다. Claude 주간이 대표이며 현재 세션은 앱·위젯에 별도로 표시한다. Claude 버튼의 세션·주간 두 숫자가 모두 검증돼야 두 한도를 갱신한다. 한쪽 실패·부분 결과는 전체 읽기를 중단하며 두 이전 숫자·확인 시각을 유지한다.
- 읽기는 저장소를 바꾸지 않으며 이전 유효 v1 숫자는 앱의 명시적 저장 때 원래 한도로만 옮긴다. 기존 v2를 덮어쓰지 않는다. 연결 해제는 해당 서비스의 모든 한도·이전 형식 숫자와 메모리 세션을 지운다.
- 1시간 뒤 지난 확인으로 구분하고 자동 웹 갱신은 하지 않는다. 위젯은 캐시만 표시하며 예시에는 실제 숫자를 섞지 않는다. 빌드15의 넓은 웹 화면·키보드 대응·Google/새창 제한·부모 화면 보존·복귀를 유지한다.
